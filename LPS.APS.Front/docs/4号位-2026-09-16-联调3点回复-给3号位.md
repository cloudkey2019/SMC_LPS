## 一、3 个联调点回复

### 1. ① 403 信封与 apsHttp 解包是否兼容？

**答：✅ 兼容，无需修改。**

依据：[frontNew/src/api/aps-v1/http.ts L48-63 unwrap](frontNew/src/api/aps-v1/http.ts#L48-L63) + [frontNew/src/api/aps-v1/types/common.ts L37-40 isApsSuccessCode](frontNew/src/api/aps-v1/types/common.ts#L37-L40)。

**机制**：
- `unwrap` 按 `isApsSuccessCode(payload.code)` 判定 → 仅 200/201 视为成功，其他 code 抛 `ApiError(code, message, traceId, timestamp)`
- 前端 `try { ... } catch (err) { if (err instanceof ApiError && err.code === 403) ... }` 即可识别 scope 越界
- ElMessage 自动弹后端 message（@see [http.ts L131](frontNew/src/api/aps-v1/http.ts#L131)）

**前端范围越界处理**（已就绪，无需改）：
- DemandProtection.vue 提交按钮 + 表格请求失败 → 自动 `ElMessage.error('业务范围越界（domain）：...')`
- 4号位 业务页面均已 try/catch ApiError，403 显示后端 message，不抛白屏
