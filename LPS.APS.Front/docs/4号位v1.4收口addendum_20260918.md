## 五、错误页统一拦截（v1.4 投产前必备）

**改动文件**：`frontNew/src/api/aps-v1/http.ts`

| 场景 | 改动前 | 改动后 |
|---|---|---|
| 网络断 / DNS 失败 / 超时 | ElMessage.error 弹 toast 后用户需手动操作 | `window.location.replace('/500')` |
| 后端 5xx | ElMessage.error 弹 toast | 同上 |
| 401 refresh 失败 | userStore.logout() + ElMessage.error | + `window.location.href='/login?redirect=...'` |

**辅助函数**（`http.ts` L143-159）：
- `redirectToLogin()` — 不在 `/login` 才跳，附带 `redirect` 参数
- `redirectToError(code)` — 当前不在目标错误页才跳，500 用 `replace` 避免返回栈污染

**现有 500.vue**（`views/Error/500.vue`）：保持不变，已具备「点按钮跳首页」能力。
