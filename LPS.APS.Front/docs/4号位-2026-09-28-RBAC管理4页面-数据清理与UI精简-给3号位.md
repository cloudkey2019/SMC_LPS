## 一、问题陈述（admin 实测 09-28）

`/aps/rbac-users` + `/aps/rbac-roles` + `/aps/rbac-permissions` + `/aps/rbac-scopes` 4 个页面 admin 实测发现 5 类问题：

| 类 | 问题 | 阻塞范围 | 责任方 |
|---|---|---|---|
| **D1 数据多余** | 30+ TEST-USER / 20+ aps.verify.role / 41 aps.verify.* 权限码 全是 verify 脚本残留 | admin 4 页面视觉混乱 | **3 号位 后端 + 4 号位 verify 脚本** |
| **D2 UI 无用提示** | RbacPermissions.vue 顶部 ElAlert（"权限码由系统定义..."）| 视觉冗余 | **4 号位 自闭环** |
| **D3 UI 无用提示** | RbacScopes.vue 顶部 ElAlert（"范围类型与值创建后不可修改..."）| 视觉冗余 | **4 号位 自闭环** |
| **D4 无分页** | 4 个页面均无分页（前端表格一次拉全表）| 生产规模后性能 / UX 退化 | **3 号位 后端 + 4 号位 UI** |
| **D5 缺批量操作** | 30+ 测试行一行一行删太低效 | admin 运维效率 | 3 号位（接口） / 4 号位（UI）|

**根因归类**：
- D1 是 **verify 脚本不清理** + 后端**没有兜底机制**双重原因
- D2/D3 是 **4 号位 UI 设计冗余**（前端自闭环）
- D4/D5 是 **后端契约缺失**（前端能做的有限）
