## 一、`planVersionId is required` 是正确行为（非 bug）

`OrderQueryController.QueryOrders` 签名 `[FromQuery] int planVersionId`（非空、无默认值 = 必填）。**订单按 PlanVersion 分区，planVersionId 是设计上必填**。前端漏传 → 框架 400。这是对的，后端故意如此。

## 二、背后还有分页契约错位（已修）

端点原参数是 **`skip`/`take`**，**没有 `pageIndex`/`pageSize`**。前端一直传 `pageIndex/pageSize`，被静默忽略（回默认 skip=0/take=50）——**分页实际从未生效**，只是之前碰巧带上了 planVersionId 没炸。

**本次后端已补**：

| 新参数 | 语义 | 映射 |
|---|---|---|
| `pageIndex` | 页码（1 起） | `skip = (pageIndex-1)*take` |
| `pageSize` | 每页条数 | `take = pageSize` |
| `skip`/`take`（原有） | 0 起偏移/条数 | 向后兼容 |

`planVersionId` **仍必填**；`dotnet build LPS.APS.Web` → **0 Error**。

## 三、现在正确调用

```bash
GET /api/order-query?planVersionId=1001&pageIndex=1&pageSize=10
# → 第 1 页 10 条，skip=0, take=10，分页真正生效
```
