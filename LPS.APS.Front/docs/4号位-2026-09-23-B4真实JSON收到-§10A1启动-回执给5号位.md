### 2.2 与反推不同（1/22 字段）—— `mtS_InstructionNo`

| 反推样本 | dev 实跑 | 差异 |
|---|---|---|
| `mtsInstructionNo` ❌ | `mtS_InstructionNo` ✅ | System.Text.Json CamelCase 对 `MTS_InstructionNo` 实际产出 `mtS_InstructionNo`——首字母小写 + 下划线不处理 + 大写 T 不切词 |

→ **前端 TypeScript 接口**（如需引用该字段）应使用 **`mtS_InstructionNo`**（保持与 dev 实跑命名一致）。

### 2.3 包装格式补充

| 项 | dev 实跑 |
|---|---|
| 外层 `code` | `0`（业务码 0 = 成功，非 HTTP 200）|
| 外层 `message` | 实跑会是具体消息（Swagger 占位 "string"）|
| 外层 `data` | 数组（每项 OrderListItemDto）|
| 外层 `traceId` | 实跑为真实追踪 ID（Swagger 占位 "string"）|
| 外层 `timestamp` | ISO 8601 with 毫秒 + UTC（与 DateTime 字段同格式）|

### 2.4 DateTime 格式

| dev 实跑 | 说明 |
|---|---|
| `2026-09-23T07:57:00.969Z` | ISO 8601 + 毫秒 + UTC（System.Text.Json 默认）|

→ 前端 ISO 8601 解析无需特殊处理；Date 类型直接构造。
