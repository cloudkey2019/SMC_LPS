**4 号位 答复**：

> ✅ **接受字符串版本号**（贴近真源，符合 §二.3 推荐方案）

**理由**：
1. 真实数据即字符串（V1 / RS-DEMO-V2），无需前端解析/映射
2. 字符串版本号可携带语义（`RS-DEMO-V2` 比 `2` 更易识别）
3. UI 渲染少一次 `v` 前缀拼接（直接 `{{ r.currentVersionCode }}`）
4. 减少一处前后端口径漂移点

**4 号位 改动计划**（详见 §三）：`RuleSetSummaryDto.currentVersion: number` → `currentVersionCode?: string`；`draftVersion` → `draftVersionCode?: string`；渲染处去除 `v${...}` 拼接。
