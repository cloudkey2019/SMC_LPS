## 二、DTO 复核（3.1 / 3.2）

### 3.1 Manual ETA Upsert

| 问题 | 回答 |
|---|---|
| PascalCase payload 能否反序列化？ | ✅ **可以**。ASP.NET Core System.Text.Json 默认 case-insensitive，PascalCase / camelCase 均可接收 |
| CreatedBy 如何处理？ | 后端 Upsert 逻辑：首次创建时写入 CreatedBy = UpdatedBy（同一字段），更新时保留原 CreatedBy、仅更新 UpdatedBy |
| actor→UpdatedBy 映射文档？ | **不需要补充**。前端将 actor 赋值给 UpdatedBy 即可，后端不感知 actor 字段 |

### 3.2 Manual ETA Cancel

| 问题 | 回答 |
|---|---|
| PascalCase body 能否接收？ | ✅ **可以**。同上，case-insensitive |
| reason 是否可选？ | ✅ **可选**。后端定义为 `string? Reason`（nullable），前端不传即为 null |
| 软删除 isActive=false？ | ✅ **一致**。后端 Cancel 操作即设置 `IsActive = false`，保留记录不物理删除 |
