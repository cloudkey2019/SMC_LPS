## 四、Dialog UX 行为（请 3号位 知悉）

| 场景 | UI 表现 |
|---|---|
| 正常（读回成功）| Dialog 顶部 warning Alert（不再 error）；文案「已根据后端读回端点预勾选当前生效项」；列表按 id 预勾选 → 用户调 → 二次确认 → 覆盖式 PUT |
| 读回失败（403/500/网络）| 顶部 Alert 升 type=error，加粗「⚠️ 读取现有分配失败，本弹窗不代表当前生效配置」；列表全不勾选（= 默认清空提交风险）→ 用户必须肉眼核对 → 二次确认 |
| loading 中 | v-loading 遮罩「正在加载当前分配…」；禁用所有 checkbox / 全选 / 清空 / 关闭按钮 |
| 提交按钮 | submitting 中显示 loading；空数组 = 「确认清空」，非空 = 「确认替换」|

**红线保持**：覆盖式 PUT 行为不变 → 二次确认 + 计数文案 + 「此操作不可撤销」三件套。
