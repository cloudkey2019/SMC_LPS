## 📋 版本变更概述

v2.2 版本基于 **2026年3月21-22日的架构文档更新**，主要涉及：
- 库存架构重构（五层架构）
- MaterialCode 编码规则明确化
- ext_ 视图建库位置统一
- 主数据契约升级
- 新增 6 条架构红线

## 🔄 主要变更内容

### 1. 必读文档清单更新

**新增必读文档**：
- `APS文档更新总结_2026-03-21至22.md`（⭐ 必读第一位）
- `开发规则变更通知_2026-03-23.md`（⭐ 必读第二位）

**版本更新**：
- `APS_数据架构与防腐层设计方案_v1.0.md`：已更新（新增库存契约视图、MaterialCode编码规则）
- `APS_数据库字段说明文档_完整版_v3.0.md`：已更新（新增 ext_ 视图定义、库存五层架构说明）

### 2. 统一开发规则文件更新

**文件位置**：`.windsurf/rules.md`

**新增 6 条架构红线**：
- 红线8：ext_ 视图建库位置统一（所有 ext_ 视图必须在 APS_Production 库创建）
- 红线9：库存表主键规范（使用物理主键，禁用 MaterialCode）
- 红线10：MaterialCode 编码规则（格式、版本号使用原则）
- 红线11：主数据契约升级规范（v1.2 字段支持）
- 红线12：库存五层架构规范（五层数据流）

**详细内容**：请查看 `.windsurf/rules.md` 文件

### 3. 内部契约文件更新

**文件位置**：`.windsurf/contracts/internal-contracts.yml`

**版本升级**：v1.0 → v2.0

**新增类型定义**：
- `MaterialSupplyContext`：物料供给上下文
- `InventorySupplyCandidate`：库存候选供给池
- `ProductFamilyInventoryScope`：产品族库存范围规则
- `InventorySourceRule`：库存来源规则
- `InventoryBalance`：库存可用余额
- `IInventoryFilterRule`：库存筛选规则接口

**更新类型定义**：
- `Material`：新增 Spec 字段，废弃部分字段
- `MaterialMapping`：新增 Spec、ERP_Warehouse、MES_Location 字段
- `InventoryFact_ERP`：主键更新为 MasterID + Warehouse
- `InventoryFact_MES`：主键更新为 MES_ID + Location

**新增说明章节**：
- 库存五层架构说明
- MaterialCode 编码规则
- 契约视图说明

**详细内容**：请查看 `.windsurf/contracts/internal-contracts.yml` 文件

### 4. 2号位职责重大更新

**新增专属职责**：
- 创建所有 ext_ 跨库包装视图在 APS_Production 库（5个视图）
- 修改 sp_SyncMaterialMapping 存储过程引用路径
- 实现库存五层架构（9张新表/视图）
- 实现 MaterialSupplyContext 表
- 修改库存事实表主键定义
- 协调 ERP DBA 和 MES DBA 创建/升级契约视图

**新增专属文档**：
- `APS文档更新总结_2026-03-21至22.md`（必读）
- `开发规则变更通知_2026-03-23.md`（必读）

**详细任务清单**：请查看 `开发规则变更通知_2026-03-23.md` 中的"2号位新增职责"章节

### 5. 其他号位注意事项

**1号位**：
- 排程引擎需要从 `InventoryBalance` 获取库存
- 理解库存五层架构的数据流

**3号位**：
- API 中涉及库存查询的接口需要调整
- 理解 ext_ 视图的新位置

**4号位**：
- 前端展示物料信息时，优先使用 `Spec` 字段
- MaterialCode 用于业务逻辑，Spec 用于展示

**5号位**：
- 实现 `IInventoryFilterRule` 接口（新增）
- 库存分配规则需要基于 `InventoryBalance`
