## 四、3 号位 需要出的 SQL（建议模板）

```sql
-- =====================================================================
-- APS dev seed: OPM 治理页 - MaterialId={由3号位指定} 下 6 条 RoutingOperation
-- (覆盖三态 + 中文工序名 + dev-only)
-- Date: 2026-09-XX  |  Author: 3-hao (rule/parameter governance, OPM Owner)
-- Why: 4号位 Opm.vue dev 联调收口需真实 RoutingOperation 数据
-- What: INSERT 6 条 RoutingOperation（MaterialId=X，OPM 分布 2/2/2）
-- DB:   APS_Production. INSERT only, no DDL (red-line #6 compliant).
-- Idempotent: guarded by (MaterialId, OperationCode).
-- NOTE: file must be executed with  -f 65001  (UTF-8)  on sqlcmd.
-- WARNING: dev-only seed; NEVER run against production.
-- =====================================================================

SET NOCOUNT ON;

DECLARE @materialId INT = X;  -- 由 3 号位 指定（dev 已 seed 的 Material）

-- Idempotent guard: (MaterialId, OperationCode) 唯一
IF NOT EXISTS (
  SELECT 1 FROM RoutingOperation
  WHERE MaterialId = @materialId AND OperationCode = N'OP10'
)
BEGIN
  INSERT INTO RoutingOperation (
    MaterialId, ProductionDepartmentId, RouteCode, PathId,
    OperationCode, OperationName, ProcessType, StageCode, OperationPlanningMode,
    StandardDuration, SetupTime, IsActive, CreatedAt, UpdatedAt)
  VALUES
    (@materialId, 3, 'DEFAULT', 1, N'OP10', N'精修',     'MACHINING', 'SMT', 'FINITE_RESOURCE', 30, 0, 1, GETDATE(), GETDATE()),
    (@materialId, 3, 'DEFAULT', 1, N'OP20', N'清洗',     'CLEANING',  'SMT', 'UNCONSTRAINED',   15, 0, 1, GETDATE(), GETDATE()),
    (@materialId, 3, 'DEFAULT', 1, N'OP30', N'转运',     'TRANSFER',  'SMT', 'WAIT_ONLY',        5, 0, 1, GETDATE(), GETDATE()),
    (@materialId, 5, 'DEFAULT', 2, N'OP40', N'装配',     'ASSEMBLY',  'ASM', 'FINITE_RESOURCE', 45, 0, 1, GETDATE(), GETDATE()),
    (@materialId, 5, 'DEFAULT', 2, N'OP50', N'老化测试', 'TESTING',   'ASM', 'WAIT_ONLY',       60, 0, 1, GETDATE(), GETDATE()),
    (@materialId, 7, 'ALT',     3, N'OP60', N'包装',     'PACKAGING', 'PKG', 'FINITE_RESOURCE', 10, 0, 1, GETDATE(), GETDATE());

  PRINT N'-- Inserted 6 RoutingOperation rows for MaterialId=' + CAST(@materialId AS NVARCHAR(10));
END
ELSE
BEGIN
  PRINT N'-- Already seeded (MaterialId, OP10) exists, skip --';
END

-- Verify echo
SELECT Id, OperationCode, OperationName, OperationPlanningMode, StandardDuration, IsActive
  FROM RoutingOperation
  WHERE MaterialId = @materialId
  ORDER BY OperationCode;
```

→ **3 号位 改 2 处**：
1. 第 15 行 `@materialId INT = X` → 填真实 demo MaterialId
2. 文件名 `APS_OPM_dev_seed_202609XX.sql` → 改日期

→ **3 号位 可改**：ProductionDepartmentId 范围（3/5/7）若 dev 有不同 seed，适配即可；中文名/工时/RouteCode 等与 §三 建议一致即可。
