## 三、修订提值（请 3号位 落 ParameterSetVersion）

| 参数 | 修订默认值 | 允许范围 | 实证依据 |
|---|---|---|---|
| `SetupSearchBudget` | **500（维持）** | **[100, 5000]（维持）** | 500 为收益/耗时平衡点（ΣSetup 减半且端到端反而快于基线——Setup 缩短使占用链变紧、槽查找加速）；上限 5000 实测 220s，仍距红线余量 75% |
| `SetupMaxNeighborhoodTries` | **50（维持）** | **[10, 500]（维持）** | 50→150 边际收益弱（降幅主要来自总预算而非停滞上限），大段场景瓶颈在预算 |

**红线实证（抄 0号位）**：最不利点（budget=5000）端到端 **220s << 900s（15 分钟）**，「有界搜索 + 不破夜间总目标」双红线达标；120s 全局时钟守护未触发（实现细节兜底仍在）。

## 四、标定发现（定性，供治理与数据侧参考）

1. **预算收益递减曲线**：1→500 增益巨大（-50.5%）；500→5000 递减（再 -22pp，耗时 +47s）。默认 500 合理，重 Setup 工艺产线可在允许范围内上调。
2. **规则密度是增益天花板**：首轮标定（一需求一物料、EXACT 稀疏）中 ΣSetup 几乎全由 DEFAULT（与顺序无关）构成 → **序列优化零空间**。EXACT 产品对规则越全，优化收益越大——**呼应 v1.2 §十八：车间优先补高频转换/长换型规则，数据质量直接决定算法收益**（4号位 缺失查询页的价值实证）。
3. **超线性但可控**：1 万 Task 端到端 2.4s → 10 万 Task 173~220s（约 O(n^1.3~1.4)，含 Phase5 索引加固后），90 天口径下余量充足。
4. **附带收益**：序列优化在「不新增延期+总延期不升」红线内仍顺带消除了 36%~50% 的延期需求（重排把 Task 拉回交期内的合法增益）。

## 五、复核触发条件（本报告数值的有效期）

以下任一发生，1号位 按同工装复测并提请 ParameterSetVersion 修订：
- **真实资源日历接入**（班次/节假日/维修四源合成，2号位）——生产日窗口切分后段变小变多，预算利用效率与段数均变化，单窗口口径数据失效；
- 生产规模/形态显著偏离标定场景（Task 数 >15 万、或 Setup 规则密度 >30%）；
- 夜间总性能目标调整（0号位）。
