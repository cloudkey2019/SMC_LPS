## 二、无设备小工序与人工有限产能（2026-09-21 联合冻结）

**业务基线 v1.7 §联合冻结补充 + DDL v5.1.8.2 物理落地**：

| # | 裁决事项 | 0号位 冻结结论 |
|---|---|---|
| 10 | **OperationPlanningMode 载体** | **`RoutingOperation` 加列**：`OperationPlanningMode NVARCHAR(32) NOT NULL DEFAULT 'FINITE_RESOURCE'` + CHK 三态（`'FINITE_RESOURCE'/'UNCONSTRAINED'/'WAIT_ONLY'`）——**非独立表** |
| 11 | 三态业务语义 | FINITE_RESOURCE 进入有限 Solver 占 Resource 时间轴；UNCONSTRAINED 保留工艺时间与依赖、不占资源；WAIT_ONLY 只表达等待时间；**不再以「有设备/无设备」判断** |
| 12 | **人工资源模型** | 复用 `Resource + ResourceCalendar + OperationResourceEligibility`；ResourceType 值域增 `HUMAN`；人工资源日历 **APS 维护**、MES 仅 ETL 来源；**禁** HumanSolver/WorkerSolver/独立人工排产模型 |
| 13 | Setup 模型 | Setup 作为 **Resource Timeline 约束**；规则继续由现有 Rule/Parameter 体系承载；不新增 SetupRuntime/SetupExecutionResult/SetupTask |
| 14 | 领域职责边界 | 1号位 消费 OPM+Resource 约束、负责求解；2号位 加载规划属性+结果持久化（不生成 FinalTask）；**3号位 规则与参数治理**；4号位 配置页面；5号位 事实查询、不负责 Solver |
| 15 | 不新增表 | OperationSupply / OperationPegging / CandidateInput / ScenarioInput / SetupRuntime（保持） |
