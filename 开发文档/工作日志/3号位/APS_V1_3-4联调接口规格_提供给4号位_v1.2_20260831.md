# 二、G2-b：甘特图数据 DTO 字段扩展（缺口 A + C）

> 对应 v1.1 §二-G2 甘特图（`GET /api/schedule/gantt/{planVersionId}`）。v1.1 最小集全部保留，本子节为**增量新增字段**。扩展后 `GanttDataDto` 仍为 `{ Resource[] , Task[] }` 结构，本子节分别扩展 Resource 与 Task。

## 2.1 字段分档原则

- **档① 3号位 可直接投影（v1.2 立即实现）**：数据已在 3号位 可读事实源（PlanVersion/域主数据/FinalTaskDraft），无需新依赖。
- **档② 依赖排程/根因结果事实（v1.2 结构预留、返回 null，v1.3 待 2号位/1号位 对齐后填充）**：字段**进 DTO 结构、置可空、未就绪返回 null**，不阻塞联调。

## 2.2 Resource 增量字段

| 字段 | 类型 | 可空 | 分档 | 取值 / 说明 |
|---|---|---|---|---|
| `domainKey` | string | 否 | 档① | 资源所属域标识（U01 多 Domain 染色分组） |
| `factoryName` | string | 是 | 档① | 工厂名称（域主数据投影） |
| `productionDepartmentName` | string | 是 | 档① | 生产部门名称 |
| `stage` | string | 是 | 档① | 工序阶段标识/名称 |
| `unavailableWindows[]` | `[{from,to,reason,impactedTaskIds[]}]` | 是 | 档② | 设备不可用窗口（U20 设备故障仅展示不自动 Pause）；未就绪返回 `null` 或空数组 |

## 2.3 Task 增量字段

| 字段 | 类型 | 可空 | 分档 | 取值 / 说明 |
|---|---|---|---|---|
| `domainKey` | string | 否 | 档① | 任务所属域标识（U01） |
| `netQty` | decimal | 是 | 档① | 净需求数量（U05） |
| `plannedProcessQty` | decimal | 是 | 档① | 含良率补偿数量（U05 净需求 vs 含良率） |
| `mesEligible` | bool | 否 | 档① | MES 下发资格（U16；从 FinalTaskDraft 投影） |
| `mesIneligibleReasons[]` | `string[]` | 是 | 档① | 不可下发原因（U17；取值域按 4号位 主文档第 16 节硬枚举：`CANDIDATE`/`UNLOCATED`/`NO_PI`/`PLANNING_PLACEHOLDER_DEPENDENCY`/`OUT_OF_DISPATCH_WINDOW`/`CANCELLED`/`OUT_OF_FROZEN_WINDOW` 等） |
| `crossDomainBlocked` | bool | 否 | 档① | 跨域阻挡标记（U14） |
| `crossDomainBlockReason` | string | 是 | 档① | 跨域阻挡原因（复用 G7 域依赖） |
| `lockMarker` | string?/bool? | 是 | 档② | Demand Protection 锁标记（U08）；未就绪返回 `null` |
| `taskShare[]` | `[{orderId,orderNo,shareQty,shareRatio}]` | 是 | 档② | 多 Order 共担一个 Task（U04）；未就绪返回 `null` |
| `taskSegments[]` | `[{segmentSeq,startTime,endTime,qty,qtyRatio,reason}]` | 是 | 档② | 数量-时间分段（U06，40+60 不压成 100）；未就绪返回 `null` |
| `delayReasons[]` | `[{reasonCode,issueCategory,severity,description,relatedObjectRef,impactHours}]` | 是 | 档② | 延期原因明细（根因优先，不只 `DUE_DATE_RISK`）；`issueCategory` 枚举沿用 v1.1 §三（`DATA_ISSUE`/`SCHEDULING_ISSUE`）；未就绪返回 `null` |
| `factType` | string | 是 | 档② | `FACT/RESULT/ESTIMATED/RECOMMENDATION`（4号位 主文档 §二.2 四类信息标签）；未就绪返回 `null` |
| `upstreamStageBlocked` | bool | 是 | 档② | 上游工序阶段阻挡；未就绪返回 `null` |
| `upstreamStageCode` | string | 是 | 档② | 上游阻挡阶段编码；未就绪返回 `null` |

> **性能取舍（沿用审计建议）**：列表型字段（`taskShare[]`/`taskSegments[]`/`delayReasons[]`/`unavailableWindows[]`）一律**可空 List**，避免一次拉全量 Reason；后端按需懒投影。

# 三、H1：候选对比复合查询端点（缺口 B）

> v1.2 新增端点（v1.1 §0.1 约定：新增接口统一 `ApiResponse<T>` 包络）。

## 3.1 端点规格

| 项 | 规格 |
|---|---|
| 方法+URL | `GET /api/Governance/plan-version/{candidatePlanVersionId}/compare-with/{basePlanVersionId}` |
| 用途 | Candidate 对比页核心数据：候选 vs 基础的 Task/Order 影响（U10） |
| 入参-Path | `candidatePlanVersionId`(int, 必填 >0)、`basePlanVersionId`(int, 必填 >0) |
| 出参-200 | `ApiResponse<CandidateComparisonDto>`：`{ success:true, data:{ TaskChangeSummary, ImpactSummary, BaseSummary, CandidateSummary }, error:null, meta }` |
| 校验规则 | 两版本存在（否则 404）；候选 `Status=CANDIDATE`（否则 400）；基础可任意状态 |
| 详细需求 | 复用 PlanVersionRepository 双版本 JOIN；`TaskChangeSummary` 基于 FinalTask 主键差集（新增/移除/时间平移/资源变更）；`crossDomainBlocked` 复用 G7 域依赖 |

## 3.2 出参结构

```jsonc
{
  "success": true,
  "data": {
    "taskChangeSummary": {
      "added": 0,                // 新增任务数
      "removed": 0,              // 移除任务数
      "timeShifted": 0,          // 时间平移任务数
      "resourceChanged": 0,      // 资源变更任务数
      "crossDomainBlocked": 0    // 跨域阻挡任务数
    },
    "impactSummary": {
      "impactedOrderCount": 0,   // 受影响订单数
      "newDelayCount": 0,        // 新增延期数
      "crossDomainImpacted": 0,  // 跨域影响数（复用 G7）
      "estimatedOnlyCount": null // ⚠ 2号位 边界，未对齐前返回 null
    },
    "baseSummary":   { "planVersionId": 0, "versionCode": "", "status": "", "computedAt": null },
    "candidateSummary": { "planVersionId": 0, "versionCode": "", "status": "", "computedAt": null }
  },
  "error": null,
  "meta": null
}
```

## 3.3 边界说明（需 2号位 对齐）

- `ImpactSummary.estimatedOnlyCount`（订单级估算数）：归 **2号位**（4号位 主文档 §7），v1.2 返回 `null`。
- `reasons[]`（原因明细：reasonCode/description/factType）：**3号位/2号位 边界灰区**，需 2号位 文档确认后单独约定；v1.2 **不在本端点返回**。
- 验收点：U10（对比）/ U11 / U12（不可激活）/ U13（确认可追溯）/ U14（跨域阻挡）。
