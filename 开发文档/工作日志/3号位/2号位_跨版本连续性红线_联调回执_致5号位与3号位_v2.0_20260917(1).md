## 一、问题一【归 5号位】数据充分，但 `BuildExistingExecutionContexts` 只算出 1 个 `DerivedRemainingQty>0`

### 现象

红线日志：`[Pegging][Continuity] 明细: 上下文总数=406, DerivedQty>0=1, ΣE=1000`，
`分桶完成: Continuation=1片 ΣE=1000, Free=0片`。只有 1 个上下文算出正的连续份额 E，其余 405 个
在制上下文 E=0 → Continuation/Free 无法同现。

### 数据证据（数据充分，不是数据问题）

```sql
WITH p328 AS (SELECT DISTINCT MTS_InstructionNo pi FROM [Order] WHERE PlanVersionId=328)
SELECT
  (SELECT COUNT(*) FROM MESWorkOrderSnapshot w
     WHERE w.ScheduleRunId=477 AND w.WorkOrderStatus='IN_PROGRESS'
       AND w.ProductionInstructionNo IN (SELECT pi FROM p328)) AS inProgressWOs,       -- 428
  (SELECT COUNT(DISTINCT s.ProductionInstructionNo) FROM StageProgressSnapshot s
     WHERE s.ScheduleRunId=477 AND s.RemainingQty>0
       AND s.ProductionInstructionNo IN (SELECT pi FROM p328)) AS stageRemainPIs,       -- 3292
  (SELECT SUM(CASE WHEN GoodQty<PlannedQty THEN 1 ELSE 0 END) FROM OperationProgressSnapshot o
     WHERE o.ScheduleRunId=477
       AND o.ProductionInstructionNo IN (SELECT pi FROM p328)) AS opRemain;            -- 1791
```

428 个 `IN_PROGRESS` 工单 + 3,292 个 stage 剩余 PI + **1,791 行工序未完工（GoodQty<PlannedQty）**，
理应对应大量 `DerivedRemainingQty>0`，却只有 1 个 → 归零发生在计算逻辑，不在输入。

### 定位（读 `LPS.APS.BusinessRules/Calculators/ProductionInstructionPositionCalculator.cs` 的
`BuildExistingExecutionContexts`，5号位代码我未改动）

- **B**：工序 frontier 匹配按 `op.MESWorkOrderNo == wo.MESWorkOrderNo && op.StageCode == startStageCode`
  过滤，未按 `MESWorkOrderNo` 正确对齐时 `remainingOps` 为空 → 落入「全部完成」分支把
  `derivedRemainingQty` 归 0（约 L1211-1214 / L1267-1270）。
- **C**：`DerivedRemainingQty` 公式 + `:0` 丢工单（部分工单算出 0 后被丢弃/覆盖）。
- **D**：`OrderByDescending` 方向反 + 用 OperationSequence 而非拓扑前沿定位工序。
- **Stage 兜底**：取 `RemainingQty`（剩余）而非完成量，作为工序级未覆盖时的兜底值。

### 请求 + 验收

请 5号位 确认并修 B/C/D + Stage 兜底口径。修完后 2号位 重跑 `ContinuityRedLineIntegrationTest`（328,
251L）：`DerivedQty>0` 应从 1 升到接近在制工单量级（428 量级），`分桶完成: Continuation=N片 / Free=M片` 同现。

```sql

  SELECT DISTINCT o.MaterialId FROM [Order] o

  SELECT DISTINCT m.Id
  FROM ext_MES_APS_Routing_Operation_View v

       SUM(CASE WHEN s.Id IS NULL THEN 1 ELSE 0 END) noSrcOp

-- 结果：tot=6182, hasSrcOp=7, noSrcOp=6175
```
