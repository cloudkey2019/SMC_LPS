## 二、C 路径改动建议（仅 3号位）

### 2.1 `CtpEvaluateRequest.DomainKey` 改 optional

`lps/LPS.APS.Web/Controllers/CtpController.cs`（约行 57-62）：

```csharp
// 现：[Required(ErrorMessage = "DomainKey 必填")]
//     public required string DomainKey { get; init; }

// 改：移除 [Required] + 去掉 required
//     public string? DomainKey { get; init; }
```

### 2.2 `CtpService.EvaluateAsync` 入口加 resolve 逻辑

`lps/LPS.APS.Web/Services/CtpService.cs`：

```csharp
public async Task<CtpResultDto> EvaluateAsync(CtpEvaluateRequest request, CancellationToken ct)
{
    if (string.IsNullOrEmpty(request.DomainKey))
    {
        request.DomainKey = await _domainResolver.ResolveAsync(
            request.MaterialCode,
            request.FactoryCode,
            ct);
    }
    // ... 既有逻辑（_dataScopeService.EnsureInScopeAsync 不动）
}
```

- `_domainResolver` 由 3号位 视既有仓储自行决定（按物料主数据 + 工厂映射即可，**无需新增表**）
- **解析失败**：返 400 `ApiResponse.Fail("无法自动确定 DomainKey")`（**不要 422**——422 = 模型校验错，400 = 业务错）

### 2.3 不动：F-G4 业务范围校验

`_dataScopeService.EnsureInScopeAsync(..., request.DomainKey, ...)` **仍在**，仅放宽「前端是否必填」，scope 校验职责不变。
