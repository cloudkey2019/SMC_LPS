# 2号位致3号位：MES 路由依赖视图缺边取证（6166535）

**日期**：2026-09-15
**主题**：`MES_APS_Routing_Dependency_View` 输出的先后边（RoutingDependency）缺中间段，导致 APS 侧 DAG 断链
**请查**：你维护的 `MiddleRoutingData` / `MiddleRoutingDataJ` 两张中间表 → `MES_APS_Routing_Dependency_View`

## 一、结论

同一物料下，**工序节点是齐全的，但「当前工步 → 下一工步」的先后边缺了中间段**。缺边发生在你的视图/中间表层，2号位只是忠实搬运（详见第五节声明），改 2号位存储过程、清库重灌都无效。

## 二、取证（一个物料即可复现）

- APS 侧 `Material.Id = 6166535`，对应 MES `MES_ID = 3231940`，`Source = ERP`。

**工序节点（全，10 道）** —— 来自 `MES_APS_Routing_Operation_View`：

| ProductionDeptCode | PathId | 工序 |
|---|---|---|
| 311246 | 1 | J101 / J102 / J103 / J104 / J105（5 道） |
| 311292 | 1 | J101 / J102 / J103 / J104（4 道） |
| 311621 | 1 | B102（1 道） |

**先后边（缺，仅 3 条）** —— 来自 `MES_APS_Routing_Dependency_View`：

| ProductionDeptCode | PathId | 边 |
|---|---|---|
| 311246 | 1 | J101→J102、J103→J104 |
| 311292 | 1 | J102→J103 |

**应得 vs 实得的缺口**：

- 311246 应有 `J101→J102→J103→J104→J105`（4 条边），实得 2 条，**缺 `J102→J103`、`J104→J105`**；
- 311292 应有 `J101→J102→J103→J104`（3 条边），实得 1 条，**缺 `J101→J102`、`J103→J104`**。

## 三、根因定位（收窄到你的中间表）

你的视图定义逻辑是：

```
MES_APS_Routing_Dependency_View
  = MiddleRoutingData   （当前工步 AS FromOperationCode, 下一工步 AS ToOperationCode）
  ∪ MiddleRoutingDataJ  （ProcessNum AS FromOperationCode, 下一道 AS ToOperationCode）
```

即每条边 = 中间表里的一行「某工步 + 其下一工步」。缺边说明：**上述缺失的「下一工步」配对行，要么没生成、要么该字段为空/写错**。这不是视图 SQL 的语法问题（列对齐无误），是中间表数据或生成中间表的上游逻辑缺行。

## 四、影响面（供你评估规模）

APS 侧用同口径（`MaterialId, ProductionDepartmentId, RouteCode, PathId`）全表扫出 **189 个孤立工序**（多工序路径内断链），即 MES 源缺边的大致规模，建议一并核对是否同一成因。

## 五、2号位侧声明（已排查，非我侧）

- `ext_MES_APS_Routing_Dependency_View` 是 `SYNONYM`，原样指向你库的 `MES_APS_Routing_Dependency_View`，零加工。
- `sp_SyncRoutingData` 的 Dependency 段只做：读源边 → 过滤「物料未映射 / 部门未映射 / ToOperationCode 为 NULL」→ 去重 MERGE。中间边不在任何过滤条件里，不会丢。

## 六、自查 SQL（在 MES_Integration 库执行）

```sql
-- A. 复现缺边（视图层，无中文列名依赖）
SELECT ProductionDeptCode, PathId, FromOperationCode, ToOperationCode
FROM dbo.MES_APS_Routing_Dependency_View
WHERE MES_ID = N'3231940' AND ToOperationCode IS NOT NULL
ORDER BY ProductionDeptCode, PathId, FromOperationCode;

-- B. 看两张中间表该物料各自的行（重点：J102/J104 的「下一工步」，J101/J103 的「下一道」）
SELECT * FROM dbo.MiddleRoutingData  WHERE MES_ID = N'3231940';
SELECT * FROM dbo.MiddleRoutingDataJ WHERE MES_ID = N'3231940';
```
