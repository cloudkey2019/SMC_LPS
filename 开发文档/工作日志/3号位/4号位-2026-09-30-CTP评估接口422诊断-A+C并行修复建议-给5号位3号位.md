# 致 5号位（主送）/ 3号位（抄送）：CTP 评估接口 422 诊断与并行修复建议

- **发件人**：4号位
- **主送**：5号位（CTP 页面负责人）
- **抄送**：3号位（后端 CtpController 负责人）
- **诊断日期**：2026-09-30
- **触发场景**：4号位 联调 CTP 页面（`/aps/ctp`）时 422 复现
- **修复路径**：A（5号位 即时闭环）+ C（3号位 后续优化），建议并行

---

## 一、问题现象

CTP 页面（`/aps/ctp`）提交评估请求时返回 HTTP 422：

```
[422] JSON deserialization for type 'LPS.APS.Web.Controllers.CtpEvaluateRequest'
was missing required properties including: 'domainKey'
```

- 接口：`POST /api/ctp/evaluate`
- 契约源：`lps/LPS.APS.Web/Controllers/CtpController.cs`（约行 57-62 `CtpEvaluateRequest` 定义）

---

## 二、根本原因（诊断）

后端 `CtpEvaluateRequest.DomainKey` 加了 `[Required(ErrorMessage = "DomainKey 必填")] public required string DomainKey`（F-G4 fail-closed 业务范围校验需要），但前端**没有对应支持**：

| 前端文件 | 现状 | 行号（约） |
|---|---|---|
| `frontNew/src/api/aps-v1/types/ctp.ts` | `CtpInput` 接口**无 `domainKey` 字段** | 18-29 |
| `frontNew/src/views/Aps/Ctp.vue` | 表单 reactive**无 `domainKey` 字段**，无 Domain 选择控件 | 63-71 |
| `frontNew/src/store/modules/aps/ctp.ts` | `evaluate()` 透传 input，**未补 `domainKey`** | 54-65 |

请求 JSON 不带 `domainKey` → ASP.NET Core 模型校验先于业务执行 → 422 拦截。**业务能力目前 501「核心能力待接入」被绕过**，用户走不到那一行。

---

## 三、为什么后端非要 DomainKey（F-G4）

CTP 评估要落到具体 Domain 的产能/物料库存计算，必须先经：

```csharp
await _dataScopeService.EnsureInScopeAsync(
    GetCurrentUserId(),
    DataScopeTypes.Domain,
    request.DomainKey,   // ← 这里必须非空
    ct);
```

校验「当前用户对这个 Domain 有权」，**否则可能跨域泄露产能/物料可得性**（F-G4 fail-closed）。缺 `domainKey` 校验函数无法判定，只能拒。

---

## 四、两条修法对比

| 路径 | 改动点 | 谁改 | 工作量 | 效果 |
|---|---|---|---|---|
| **A（前端即时闭环）** | 见 §六 | **5号位** | 1~2 小时 | 422 消失，页面恢复 |
| **C（后端契约优化）** | 见 §七 | **3号位** | 3~5 行代码 | 用户不需手动选；契约回归正轨 |

**建议并行**：5号位 立刻做 A 闭环；3号位 排期做 C（接入 CTP 引擎时一并改）。

## 五、并行节奏

| 阶段 | 5号位 | 3号位 | 说明 |
|---|---|---|---|

## 六、A 路径 — 5号位 改动建议

1. **`frontNew/src/api/aps-v1/types/ctp.ts`**：`CtpInput` 接口加 `domainKey: string`（**必填**）。

2. **`frontNew/src/views/Aps/Ctp.vue`**：表单顶部「物料编码」上方加：

   ```vue
   <ElFormItem label="事业部" required>
     <ElSelect v-model="form.domainKey"
               :disabled="domains.length === 0"
               placeholder="请选择事业部">
       <ElOption v-for="d in domains"
                 :key="d.key" :value="d.key"
                 :label="`${d.displayName}（${d.key}）`" />
     </ElSelect>
   </ElFormItem>
   ```

   - 数据源：`useDomainStore` 已导入可用
   - **空态兜底**：当前用户无任何 Domain 权限（仅 `aps.viewer.management`）时下拉 disabled + 提示「当前账号无任何 Domain 权限，无法评估」，避免硬提交再次 422

3. **`frontNew/src/store/modules/aps/ctp.ts`**：`evaluate()` 把 `form.domainKey` 写入 payload。

---

## 七、C 路径 — 3号位 改动建议

1. **`CtpEvaluateRequest.DomainKey`**：移除 `[Required]`，改 `string?`。

2. **`CtpService.EvaluateAsync`** 入口加解析逻辑：

   ```csharp
   if (string.IsNullOrEmpty(request.DomainKey))
       request.DomainKey = await _domainResolver.ResolveAsync(
           request.MaterialCode, request.FactoryCode, ct);
   ```

   - `IDomainResolver` 由 3号位 视既有仓储自行决定（无需新增表，按物料主数据 + 工厂映射即可）

3. **解析失败**：返 400 `ApiResponse.Fail("无法自动确定 DomainKey")`，**不要 422**（422 = 模型校验错，400 = 业务错）。

4. **F-G4 校验仍在**：`_dataScopeService.EnsureInScopeAsync(..., request.DomainKey, ...)` 不动。
