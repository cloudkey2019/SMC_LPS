## A · 致 PM（0号位）—— 2 个真口径软点

### A1 · 人工槽产能语义
- **要定**：同一 ProductionDepartment + OperationCode 存在多个 `SlotCode`（例 A部门/精修/精修01+02）时，排程如何理解并行/产能？
- **2号位 倾向**：1 槽 = 1 并行道（同一时刻 1 槽只接 1 个 Operation，多槽 = 多线并行）；V1 **不引入产能系数/效率折算**。
- **要你回**：确认「1 槽 = 1 并行道」即可，或另给多头并行/产能规则。

### A2 · EXPEDITE「可调整 Demand」实现边界
- **要定**：排除「已开工 / 已完工 / 领料事实 / Firm / Frozen / Strict Binding」之外的实现级边界——**已分配已下达但未开工**算不算可调整？**部分领料**算不算「领料事实」？
- **2号位 倾向**：套现有 Firm/Frozen/已开工语义；「未开工、未领料、非 Firm/Frozen/Strict Binding」= 可调整，V1 从宽。
- **要你回**：确认边界，或直接授权 2号位 据此自决。
