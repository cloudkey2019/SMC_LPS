## 〇、P1-04 审核结论（原文）

> 对所有可编辑的规则/参数/Domain/Governance服务，提交功能权限×Scope二次校验清单；按确有业务范围的实体落具体反证，而非盲目上通用记录级ACL平台。

## 一、总判定

- **确有业务范围维度的实体**（实体含 `ProductionDepartmentId` / Factory / Domain 等范围字段）→ 写路径落 **Scope 二次校验**（`IDataScopeService.EnsureInScopeAsync`，越界 `ScopeViolationException` → Controller 映射 403）。
- **无业务范围字段的实体**（全局版本治理工件）→ **不设记录级 ACL**（遵循审核「按确有业务范围的实体落具体反证，而非盲目上通用记录级ACL平台」——版本工件跨号位/跨部门共享，无单部门归属语义）。
- 功能权限（权限码）统一由 `[Authorize(Policy = PermissionCodes.*)]` 在 Controller 端点层强制；Scope 二次校验在服务层写路径内做**目标对象维度**的第二道校验（防 IDOR / 跨部门迁移）。
