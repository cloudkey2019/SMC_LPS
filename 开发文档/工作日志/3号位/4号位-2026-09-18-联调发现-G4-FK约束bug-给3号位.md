## 一、G4 失败详情

**verify-integration.mjs 输出**：

```
[G] Strategy Profile 12 端点
  ✅ G1 GET /strategy-profiles — code=200, count=404
  ✅ G2 GET /strategy-profile/{id}/versions — code=200, count=0
  ✅ G3 GET /strategy-profile/{id}/published-version — code=404
  ❌ G4 POST /strategy-profile/version（创建 DRAFT） — code=500
     newId={"code":500,"message":"服务器内部错误","data":{"exception":"SqlException",
     "detail":"INSERT 语句与 FOREIGN KEY 约束\"FK_StrategyProfileVersion_RuleSetVersion\"冲突。
     该冲突发生于数据库\"APS_Production\"，表\"dbo.RuleSetVersion\", column 'Id'。
     语句已终止。"}}
```

**失败点**：

- 端点：`POST /api/governance/strategy-profile/version`
- 提交 payload：
  ```json
  {
    "strategyProfileId": 1,
    "versionCode": "verify-1726616xxx",
    "ruleSetVersionId": 1,
    "parameterSetVersionId": 1,
    "isDefault": false
  }
  ```
- 报错：`FOREIGN KEY 约束"FK_StrategyProfileVersion_RuleSetVersion"冲突`，目标表 `dbo.RuleSetVersion.Id=1` 不存在
- 栈底位置：`LPS.APS.Engine/Repositories/Governance/StrategyProfileVersionRepository.cs:78 AddAsync`

---

## 三、根因

3号位 POST 端点的 `CreateStrategyProfileVersionRequest` 把 `ruleSetVersionId` 当作必填外键，但 dev 种子数据里 `dbo.RuleSetVersion` 表为空（或无 Id=1 行），导致任何 POST 都撞 FK 红线。

同理 `parameterSetVersionId` 也可能撞 FK（即使本次报错优先指 rule set）。

---

## 四、3号位 决策建议（4号位 推荐 A）

### 选项 A（推荐）：`ruleSetVersionId` / `parameterSetVersionId` 改为 nullable

**理由**：
- 4号位 文档 §十八 描述的「策略配置」页允许创建「最小可用 Profile」（仅 solverApproach + features，暂不绑定 RuleSet / ParameterSet）
- 这与 4号位 对 StrategyProfileVersion 的 6 态机理解一致：Draft 可为空配置
- 前端 StrategyDraftDialog.vue（@see `views/Aps/components/StrategyDraftDialog.vue`）表单的 ruleSetVersionId 字段当前是 optional（用户可留空），后端应为 optional 配对

**改动范围**（3号位）：
- `CreateStrategyProfileVersionRequest.RuleSetVersionId` `int` → `int?`
- `CreateStrategyProfileVersionRequest.ParameterSetVersionId` `int` → `int?`
- `StrategyProfileVersionRepository.AddAsync` INSERT 适配 nullable
- Migration（如有）

### 选项 B：dev 种子补 RuleSetVersion + ParameterSetVersion

**缺点**：
- 不能解决 production 真实场景（用户也可能创建最小 Profile）
- 治标不治本

### 选项 C：前端必填 ruleSetVersionId

**缺点**：
- 与 v1.4 §十八 「最小 Profile 可只配 solverApproach」语义不符
- 前端表单改必填 + 后端契约改必填 = 双重改动，4号位 文档已锁描述

**4号位 默认**：选项 A（如能在 9/19 前修好不阻塞联调全绿）。
