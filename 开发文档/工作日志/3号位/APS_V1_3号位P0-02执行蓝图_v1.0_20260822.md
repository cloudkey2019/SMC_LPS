### 4.3 Provider（LPS.APS.Application）

`FrozenStrategySnapshotProvider.cs`：

1. 装配处（L100-104）替换空对象为真实反序列化：

```csharp
// ⑤ Solver Strategy（P0-02：来自 ParameterSetVersion.SolverStrategyJson，缺失/损坏一律失败）
SolverStrategy = DeserializeSolverStrategyBlock(parameterSetVersion.SolverStrategyJson, parameterSetVersion.Id),
// ⑥ Candidate Guardrail（P0-02：来自 ParameterSetVersion.CandidateGuardrailJson，缺失/损坏一律失败）
CandidateGuardrail = DeserializeCandidateGuardrailBlock(parameterSetVersion.CandidateGuardrailJson, parameterSetVersion.Id)
```

2. 新增两个私有方法，**镜像现有四块模式**（P0-04 失败语义同款）：

```csharp
/// <summary>反序列化 SolverStrategyJson → SolverStrategyBlock（P0-02：缺失/损坏一律失败，不静默回退空对象）</summary>
private SolverStrategyBlock DeserializeSolverStrategyBlock(string? json, long versionId)
{
    if (string.IsNullOrWhiteSpace(json))
    {
        throw new InvalidOperationException($"参数集版本 {versionId} 的 SolverStrategyJson 为空/缺失，Snapshot 装载失败");
    }
    try
    {
        return JsonSerializer.Deserialize<SolverStrategyBlock>(json, JsonOptions)
        ?? throw new InvalidOperationException($"参数集版本 {versionId} 的 SolverStrategyJson 反序列化结果为空，Snapshot 装载失败");
    }
    catch (JsonException ex)
    {
        throw new InvalidOperationException($"参数集版本 {versionId} 的 SolverStrategyJson 格式无效，Snapshot 装载失败", ex);
    }
}
// DeserializeCandidateGuardrailBlock 同构（CandidateGuardrailJson → CandidateGuardrailBlock）
```

> 注意：**显式空块 `"{}"` 为合法表达**（P0-04 语义，与"缺失"区分）——默认值语义由 JSON 默认值承载，不再由代码 `new SolverStrategyBlock()` 冒充冻结配置。
