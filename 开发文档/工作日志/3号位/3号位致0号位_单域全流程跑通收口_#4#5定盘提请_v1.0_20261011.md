## 三、#5-① B5 归域冲突处理规则（请裁决）

### 3.1 现状（v1.1 + 2026-10-11 实测）

- **v1.1 判定**：同 scope + 同 ProductFamilyId 两启用域 → 订单跨 2 个 PV 分区（`BOMResultPullService.cs:420-427` 实测双命中）；冻结要求 DomainKey 唯一（Domain裁决 §5）但**无冲突处理规则**。
- **2026-10-11 dev 库实测**：当前 11 个启用域（FAMILY_X/FAMILY_VALVE/FAMILY_LGJ…10 个 FAMILY + BJ_FAMILY_Y/TJ_FAMILY_Y 2 个 FACTORY_FAMILY）**无同 scope 组合重复**——G2 落码的 `ExistsActiveScopeComboAsync` 判重已生效，新启用域被阻断。
- **残留歧义风险**：FAMILY 与 FACTORY_FAMILY 属**不同 scope 类型**但可指向**同 ProductFamilyId**（如 ProductFamilyId=2 下 BJ_FAMILY_Y/TJ_FAMILY_Y 按 Factory 细分，无 FAMILY 域；但理论上一订单同时命中 FAMILY 域规则与 FACTORY_FAMILY 规则时，**归域函数命中顺序歧义**）。冻结无此冲突处理规则。

### 3.2 需 0号位 裁决

**归域冲突语义**：当同一订单/物料命中多个启用域的 scope 规则时，采用何种规则？

| 候选方案 | 语义 | 影响 |
|---|---|---|
| **A. 精确度优先**（推荐） | FACTORY_FAMILY（Factory+ProductFamily）> FAMILY（ProductFamily） | 与冻结「供给侧按域归集」最贴合，Factory 维度更精确 |
| B. SortOrder 优先 | SortOrder 小者优先（当前 FAMILY_X=99 最小） | 简单但依赖维护者自觉，语义弱 |
| C. fail-closed 报错 | 多命中即 Domain 失败（硬错误，01:2485） | 最安全但阻断走查，需先清存量 |

> 附 G2 说明：3号位 已按「合法性校验」职责落码 scope 组合唯一性（防同 scope 重复启用），**不宣称冻结逐字红线**（DDL 仅 DomainKey UNIQUE）。归域优先级语义取舍**非 3号位 决策**，需 0号位 定盘。
