## 一、全流程走查：BOM → Stage → Routing → OperationPlanningMode → 1号位

### 1.1 制造路径数据链（0号位 (52)(2) 定案）

```
订单 Demand
   ↓
BOM 展开（BOM 结构不变）
   ↓
BOM Stage Path（APS_BOM_STAGE_PATH_RAW：StageCode + StageSeq + IsSupplyThreshold）
   ↓
确定物料制造路径 = MaterialId + StagePath 共同确定（非 MaterialId 单独）
   ↓
RoutingOperation 按 MaterialId + StageCode 匹配（2号位 形成完整 Routing Context）
   ↓
1号位 消费 Operation / Dependency / Stage 顺序
```

**0号位 裁决要点（(52)(2)）**：
- **Q1**：同一物料跨多个 Stage = **一个生产需求**，不拆多需求（防 Pegging 错误 / PI Position 冲突 / 有限产能链断裂）
- **Q2**：Routing 查询**必须带 Stage**，但不是只查当前 Stage——2号位 按 `MaterialId + StagePath` 加载完整制造路径，再按 `MaterialId + StageCode` 匹配 RoutingOperation
- **Q3**：1号位 **不推 Stage 顺序**；2号位 提供完整 Routing Context
- **Q4**：BOM 模型**不改**（BOM 管"需要什么"、Routing 管"怎么制造"、StagePath 管"经过哪些阶段"）
- **MaterialStageDeptContext**：**不调整**，进一步证明 `MaterialId + StageCode` 为 Key
- **Task 带 StageCode**：2号位 已加，0号位 确认正确
