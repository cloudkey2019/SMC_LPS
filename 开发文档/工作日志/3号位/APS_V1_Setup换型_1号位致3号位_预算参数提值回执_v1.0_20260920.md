## 一、提值（两参数，均为「次数」量纲，非毫秒）

### 参数 1：有界搜索预算（建议 Key：`SetupSearchBudget`）

| 项 | 内容 |
|---|---|
| 中文技术含义 | 单个「可移动段」（同 Resource × 同一连续生产窗口 × 固定锚点之间）一次有界序列优化中，邻域算子（swap / insertion / block move 及等价操作）的**总尝试次数上限**；达上限即终止该段搜索、返回当前最优 |
| 临时默认值 | **500** |
| 允许范围 | **[100, 5000]** |
| 触发条件 | 每段搜索独立计数；跨段不共享预算 |

### 参数 2：最大邻域尝试次数（建议 Key：`SetupMaxNeighborhoodTries`）

| 项 | 内容 |
|---|---|
| 中文技术含义 | 单段搜索中**连续无改善**（Level 3 目标未下降）的邻域尝试上限；达上限提前终止该段，避免在已收敛区域空耗总预算（等价 SA/禁忌的 stagnation patience） |
| 临时默认值 | **50** |
| 允许范围 | **[10, 500]** |
| 触发条件 | 任一邻域尝试产生严格改善即清零重计 |

### 量纲说明（为什么是次数不是毫秒）

两参数均定义为**次数**而非时间：次数预算下同一输入 + 同一种子 → 同一搜索轨迹 → **结果可重放**（Run 重放/审计/回归测试都依赖确定性；毫秒预算在不同机器上产生不同结果，破坏可重放性）。「不破夜间约 15 分钟总目标」的 0号位 红线由 1号位 在搜索循环外层做**全局时钟守护**兜底（实现细节，不进治理参数），双层防线。
