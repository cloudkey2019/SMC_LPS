| 控制器 | 路由域 | 归属 | 内容 |

## 1.2 关键事实

1. **3号位 未实现 Order / CTP / Explanation / PI 等 2号位/5号位 业务接口**——审计 §五 明确这些"**不在 3↔4 范围**"（v1.1 §8.3，归 2号位/1号位/5号位 数据源），前端当前走 mock。即"原来由 3号位 中转的 2号位/5号位 业务"在**代码层面并不存在**，仅存在于契约规划（G 系列统一对外）层面。
2. **3号位 现有的"非纯策略"接口** = G4（Run 列表）、G7（域依赖）、G8（域级状态）+ Schedule 三查询——均为"**2号位 形成事实、3号位 只读查询封装**"（0号位 2026-08-29 裁决 #5 授权）。
3. **5号位 现状** = BusinessRules 项目（Pegging/LotSizing/Priority 规则插件）+ `ProcurementManualEtaController` 独立控制器 + 0号位 裁决 #7 委派的 18 个测试失败专项复核。
