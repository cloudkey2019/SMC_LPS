# APS V1_4号位页面与业务操作开发实施包 v1.5

## 用户输出、接口链路、Candidate操作联合冻结版

版本：v1.5\
适用对象：4号位及开发AI

------------------------------------------------------------------------

# 一、文档定位

本版本基于9.15冻结实施包及最终职责边界调整，用于指导4号位页面与业务操作开发。

本版本不重新设计业务逻辑，只同步：

-   页面入口调整；
-   接口链路调整；
-   Candidate操作；
-   用户输出展示；
-   权限与业务操作边界。

------------------------------------------------------------------------

# 二、4号位最终职责

4号位负责：

-   页面开发；
-   用户交互；
-   展示模型；
-   输入组织；
-   操作入口。

4号位不负责：

-   Pegging计算；
-   Allocation计算；
-   Solver计算；
-   权限治理；
-   规则治理；
-   计划结果生成。

------------------------------------------------------------------------

# 三、接口链路冻结

## 治理类操作

统一：

    4号位
     ↓
    3号位
     ↓
    2号位执行

适用：

-   Candidate治理；
-   Run治理；
-   权限相关操作；
-   规则参数相关操作。

------------------------------------------------------------------------

## 业务类操作

统一：

    4号位
     ↓
    5号位
     ↓
    2号位业务Service

适用：

-   查询；
-   展示；
-   Demand Protection；
-   MES受控操作。

------------------------------------------------------------------------

# 四、禁止接口模式

禁止新增：

    4号位 → 2号位 HTTP/API

已有兼容接口：

-   仅允许迁移期保留；
-   不允许新增业务依赖。

------------------------------------------------------------------------

# 五、Candidate页面支持

页面支持：

-   Candidate创建；
-   Candidate查看；
-   Candidate比较；
-   Candidate确认。

展示：

-   BusinessTriggerType；
-   PriorityMode；
-   OrderTargets；
-   TaskTargets；
-   ChangedResourceIds；
-   BasePlanVersionId。

------------------------------------------------------------------------

# 六、Candidate页面边界

4号位负责：

-   输入收集；
-   参数展示；
-   用户确认。

不负责：

-   Scope合法性判断；
-   Base有效性判断；
-   Solver可行性判断。

以上由3号位和2号位负责。

------------------------------------------------------------------------

# 七、用户输出展示

页面展示：

-   订单计划；
-   甘特图；
-   任务列表；
-   延期原因；
-   Resource影响；
-   Setup影响；
-   Supply/Pegging追溯。

------------------------------------------------------------------------

# 八、Explanation展示边界

责任链：

    1号位
    产生解释事实

    ↓

    2号位
    保存运行结果

    ↓

    5号位
    提供查询接口

    ↓

    4号位
    展示

4号位不重新计算原因。

------------------------------------------------------------------------

# 九、Demand Protection操作

页面提供：

-   查询入口；
-   释放入口；
-   操作反馈。

实际业务校验：

由2号位执行。

权限：

由3号位控制。

------------------------------------------------------------------------

# 十、MES受控操作

页面：

提供操作入口。

链路：

    4号位
     ↓
    5号位
     ↓
    2号位业务校验

4号位不直接修改MES业务状态。

------------------------------------------------------------------------

# 十一、页面开发禁止事项

禁止：

-   页面内实现Pegging算法；
-   页面内计算排程结果；
-   页面内复制权限逻辑；
-   页面绕过正式Service调用数据库。

------------------------------------------------------------------------

# 十二、验收重点

必须验证：

1.  页面入口符合最新接口链路；
2.  Candidate操作链路正确；
3.  查询结果来自正式业务Owner；
4.  Explanation展示正确；
5.  Demand Protection操作经过业务校验；
6.  权限与业务资格分离。

------------------------------------------------------------------------

# 十三、最终冻结原则

4号位定位：

> APS V1用户交互与业务操作入口。

4号位负责让用户正确使用系统，不负责改变APS业务真相。
