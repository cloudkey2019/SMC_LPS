# APS 3号位规则参数认证权限与运行生命周期实施包 v1.3

## 20260902 双专项冻结对齐版

> 本版本替换《APS 3号位规则参数认证权限与运行生命周期实施包 v1.2》。
>
> 本次仅同步DomainDefinition治理边界与运行配置冻结机制，不扩大3号位职责范围。

------------------------------------------------------------------------

# 一、本次修订范围

本版本补充：

1.  DomainDefinition治理职责；
2.  ScheduleRun期间配置冻结；
3.  Domain规则权限边界。

不新增：

-   Domain实时计算服务；
-   Pegging逻辑；
-   Supply判断逻辑；
-   Solver逻辑。

------------------------------------------------------------------------

# 二、3号位职责定位

3号位负责：

-   规则参数治理；
-   DomainDefinition维护；
-   配置权限控制；
-   参数版本管理；
-   审计追踪。

3号位不负责：

-   ScheduleRun执行；
-   Domain Resolve运行；
-   Pegging；
-   Allocation；
-   Solver。

------------------------------------------------------------------------

# 三、DomainDefinition治理

## 1. 配置定位

DomainDefinition属于APS治理配置。

用于定义：

-   排程域；
-   域规则；
-   域依赖关系。

------------------------------------------------------------------------

## 2. 生命周期

正式流程：

    3号位维护DomainDefinition
    ↓
    配置发布
    ↓
    ScheduleRun启动
    ↓
    冻结本次运行配置语义
    ↓
    2号位执行Domain Resolve

------------------------------------------------------------------------

# 四、运行冻结规则

ScheduleRun开始后：

本次运行使用的DomainDefinition语义必须保持一致。

禁止：

-   排程过程中动态修改Domain规则；
-   当前Run读取最新未冻结配置；
-   不同订单使用不同版本规则。

------------------------------------------------------------------------

# 五、Domain Resolve职责边界

## 3号位提供

提供：

-   已认证DomainDefinition；
-   有效配置版本；
-   权限控制。

------------------------------------------------------------------------

## 2号位执行

2号位负责：

-   根据冻结配置执行Domain Resolve；
-   生成Order / Demand DomainKey。

------------------------------------------------------------------------

# 六、禁止职责扩展

3号位不得实现：

## 1. 订单实时归域

禁止：

订单进入时调用Domain判断。

------------------------------------------------------------------------

## 2. Pegging规则

禁止：

Domain配置直接参与Supply分配。

------------------------------------------------------------------------

## 3. Solver约束

禁止：

Domain配置直接控制资源求解。

------------------------------------------------------------------------

# 七、与其他号位接口

## 与2号位

输出：

-   DomainDefinition配置；
-   配置版本信息。

不输出：

-   Domain Resolve结果。

------------------------------------------------------------------------

## 与5号位

无运行计算依赖。

5号位负责事实计算。

------------------------------------------------------------------------

## 与1号位

无直接接口。

1号位消费已完成归域后的排程输入。

------------------------------------------------------------------------

# 八、冻结说明

本版本属于：

APS V1职责边界一致性修订。

保持：

-   规则参数体系；
-   权限模型；
-   运行生命周期；

不改变：

-   Pegging；
-   有限产能；
-   Task生成。
