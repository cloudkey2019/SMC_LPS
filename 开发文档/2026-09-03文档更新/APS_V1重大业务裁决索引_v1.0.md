# 六、后续变更管理

如果未来需要修改冻结事项：

必须：

1.  提交变更原因；
2.  明确影响文档；
3.  重新评估业务闭环；
4.  更新冻结版本。

不得通过：

-   修改单个实施包；
-   修改代码；
-   修改接口说明；
