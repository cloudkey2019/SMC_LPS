# 五、最终读取规则

后续AI读取项目来源时：

优先：

1.  冻结索引；
2.  业务基线；
3.  专项裁决；
4.  技术设计；
5.  实施包；
6.  审核治理。

-   使用历史版本覆盖当前版本；
-   使用讨论过程作为业务依据；
