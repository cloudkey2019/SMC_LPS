# 第四章：2号位对外契约（数据基础设施）

## 4.1 概述

2号位（数据基础设施）是APS系统的"引擎底座"，负责：
- 数据加载与持久化
- 凭证执行与状态变更
- BOM遍历与静态扫描
- 批量操作与性能优化

**核心原则**：2号位只做"苦力活"，不做业务决策。所有业务逻辑由5号位插件决定，2号位负责执行。

## 4.2 IDataLoader（数据加载接口）

### 4.2.1 接口定义

```csharp
/// <summary>
/// 数据加载接口
/// 负责从数据库加载排产所需的所有数据
/// </summary>
public interface IDataLoader
{
    /// <summary>
    /// 加载指定域的完整排产数据
    /// 性能要求：单域数据量100万行以内，加载时间 < 5秒
    /// </summary>
    /// <param name="domainKey">域标识（如"ProductFamily_A"）</param>
    /// <param name="planVersionId">计划版本ID</param>
    /// <returns>排产沙盘上下文</returns>
    Task<ScheduleContext> LoadDomainDataAsync(string domainKey, int planVersionId);
    
    /// <summary>
    /// 加载历史锚点（已下发MES的冻结Task）
    /// 用于约束排程，确保已下发任务不被修改
    /// </summary>
    /// <param name="domainKey">域标识</param>
    /// <param name="cutoffDate">截止日期（通常为当前时间 + 冻结窗口）</param>
    /// <returns>冻结任务列表</returns>
    Task<List<Task>> LoadHistoricalAnchorsAsync(string domainKey, DateTime cutoffDate);
    
    /// <summary>
    /// 加载BOM展开结果
    /// 从ODS库的BOM工作集拉取数据
    /// </summary>
    /// <param name="batchNo">BOM展开批次号</param>
    /// <returns>BOM工作集</returns>
    Task<BOMWorkset> LoadBOMWorksetAsync(string batchNo);
    
    /// <summary>
    /// 加载资源日历
    /// 包含设备的工作时间、维护时间等
    /// </summary>
    /// <param name="factoryId">工厂ID</param>
    /// <param name="startDate">开始日期</param>
    /// <param name="endDate">结束日期</param>
    /// <returns>资源日历</returns>
    Task<ResourceCalendar> LoadResourceCalendarAsync(int factoryId, DateTime startDate, DateTime endDate);
    
    /// <summary>
    /// 增量加载新订单
    /// 用于实时排程场景
    /// </summary>
    /// <param name="domainKey">域标识</param>
    /// <param name="sinceTime">增量起始时间</param>
    /// <returns>新订单列表</returns>
    Task<List<Order>> LoadIncrementalOrdersAsync(string domainKey, DateTime sinceTime);
}
```

### 4.2.2 实现示例

```csharp
public class DataLoader : IDataLoader
{
    private readonly IDbConnection _db;
    
    public async Task<ScheduleContext> LoadDomainDataAsync(string domainKey, int planVersionId)
    {
        var context = new ScheduleContext
        {
            DomainKey = domainKey,
            PlanVersionId = planVersionId,
            CurrentTime = DateTime.Now
        };
        
        // 1. 并行加载主数据
        var loadTasks = new[]
        {
            LoadOrdersAsync(domainKey, planVersionId),
            LoadMaterialsAsync(domainKey),
            LoadResourcesAsync(domainKey),
            LoadInventoriesAsync(domainKey)
        };
        
        await Task.WhenAll(loadTasks);
        
        context.Orders = await loadTasks[0] as List<Order>;
        context.Materials = await loadTasks[1] as List<Material>;
        context.Resources = await loadTasks[2] as List<Resource>;
        context.Inventories = await loadTasks[3] as List<InventoryRecord>;
        
        // 2. 识别独立需求（PRODUCTION_INSTRUCTION生产指示，v5.0.24重分类：原MTS/SS/SS_U）
        context.IndependentDemands = context.Orders
            .Where(o => o.OrderType == "PRODUCTION_INSTRUCTION")
            .ToList();
        
        // 3. 初始化空集合
        context.Tasks = new List<Task>();
        context.PeggingLinks = new List<PeggingLink>();
        context.PeggingLedgers = new Dictionary<long, PeggingLedger>();
        context.Logs = new List<ExecutionLog>();
        
        return context;
    }
    
    private async Task<List<Order>> LoadOrdersAsync(string domainKey, int planVersionId)
    {
        // 使用Dapper批量加载
        var sql = @"
            SELECT * FROM [Order]
            WHERE DomainKey = @DomainKey
              AND PlanVersionId = @PlanVersionId
              AND Status NOT IN ('CANCELLED', 'COMPLETED')
            ORDER BY Priority DESC, CustomerDueDate ASC";
        
        return (await _db.QueryAsync<Order>(sql, new { DomainKey = domainKey, PlanVersionId = planVersionId }))
            .ToList();
    }
    
    public async Task<List<Task>> LoadHistoricalAnchorsAsync(string domainKey, DateTime cutoffDate)
    {
        var sql = @"
            SELECT * FROM Task
            WHERE DomainKey = @DomainKey
              AND IsFrozen = 1
              AND PlannedStartTime <= @CutoffDate
            ORDER BY PlannedStartTime";
        
        return (await _db.QueryAsync<Task>(sql, new { DomainKey = domainKey, CutoffDate = cutoffDate }))
            .ToList();
    }
}
```

### 4.2.3 性能优化要点

1. **并行加载**：使用`Task.WhenAll`并行加载多个表
2. **索引优化**：确保`DomainKey`和`PlanVersionId`有复合索引
3. **分页加载**：超大数据量时使用分页加载
4. **缓存策略**：物料、资源等静态数据可缓存

## 4.3 IVoucherExecutor（凭证执行接口）

### 4.3.1 接口定义

```csharp
/// <summary>
/// 凭证执行接口
/// 负责根据5号位返回的凭证执行状态变更
/// </summary>
public interface IVoucherExecutor
{
    /// <summary>
    /// 执行Pegging凭证（库存扣减）
    /// </summary>
    void ExecutePeggingVoucher(PeggingVoucher voucher, ScheduleContext context);
    
    /// <summary>
    /// 执行拆批凭证（生成Task实例）
    /// </summary>
    void ExecuteSplitVoucher(SplitVoucher voucher, ScheduleContext context);
    
    /// <summary>
    /// 执行订单打分凭证
    /// </summary>
    void ExecuteOrderScoreVoucher(OrderScoreVoucher voucher, ScheduleContext context);
    
    /// <summary>
    /// 执行冻结区打标凭证
    /// </summary>
    void ExecuteFrozenMarkVoucher(FrozenMarkVoucher voucher, ScheduleContext context);
    
    /// <summary>
    /// 执行物料短缺凭证
    /// </summary>
    void ExecuteMaterialShortageVoucher(MaterialShortageVoucher voucher, ScheduleContext context);
    
    /// <summary>
    /// 执行厂间发货Task凭证
    /// </summary>
    void ExecuteShippingTaskVoucher(ShippingTaskVoucher voucher, ScheduleContext context);
    
    /// <summary>
    /// 批量执行凭证（事务性）
    /// 要么全部成功，要么全部回滚
    /// </summary>
    void ExecuteBatch(List<VoucherBase> vouchers, ScheduleContext context);
    
    /// <summary>
    /// 回滚凭证（撤销已执行的凭证）
    /// </summary>
    void Rollback(VoucherBase voucher, ScheduleContext context);
}
```

### 4.3.2 实现示例

```csharp
public class VoucherExecutor : IVoucherExecutor
{
    public void ExecutePeggingVoucher(PeggingVoucher voucher, ScheduleContext context)
    {
        // 1. 验证凭证
        var validation = voucher.Validate();
        if (!validation.IsValid)
            throw new VoucherValidationException(validation.Errors);
        
        // 2. 扣减库存
        foreach (var detail in voucher.Details)
        {
            if (detail.SourceType == "INVENTORY")
            {
                var inventory = context.Inventories.FirstOrDefault(i => i.Id == detail.SourceId);
                if (inventory == null)
                    throw new VoucherExecutionException($"库存记录不存在: {detail.SourceId}", voucher);
                
                if (inventory.AvailableQty < detail.AllocatedQuantity)
                    throw new VoucherExecutionException($"库存不足: 可用{inventory.AvailableQty}, 需要{detail.AllocatedQuantity}", voucher);
                
                inventory.AvailableQty -= detail.AllocatedQuantity;
            }
        }
        
        // 3. 创建Pegging连线
        var order = context.Orders.First(o => o.Id == voucher.OrderId);
        var material = context.Materials.First(m => m.Code == voucher.MaterialCode);
        
        foreach (var detail in voucher.Details)
        {
            context.PeggingLinks.Add(new PeggingLink
            {
                PlanVersionId = voucher.PlanVersionId,
                DownstreamTaskId = 0, // Task尚未生成
                DownstreamMaterialId = material.Id,
                SupplySourceType = detail.SourceType,
                SupplySourceId = detail.SourceId,
                Quantity = detail.AllocatedQuantity,
                LeadTimeDays = detail.LeadTimeDays,
                CreatedAt = DateTime.Now
            });
        }
        
        // 4. 更新订单的Pegging账本
        if (!context.PeggingLedgers.ContainsKey(order.Id))
        {
            context.PeggingLedgers[order.Id] = new PeggingLedger
            {
                OrderId = order.Id,
                Requirements = new Dictionary<string, MaterialRequirement>()
            };
        }
        
        var ledger = context.PeggingLedgers[order.Id];
        if (!ledger.Requirements.ContainsKey(voucher.MaterialCode))
        {
            ledger.Requirements[voucher.MaterialCode] = new MaterialRequirement
            {
                MaterialCode = voucher.MaterialCode,
                RequiredQty = voucher.RequiredQuantity,
                AllocatedQty = 0,
                SupplySources = new List<SupplySource>()
            };
        }
        
        var requirement = ledger.Requirements[voucher.MaterialCode];
        requirement.AllocatedQty += voucher.TotalAllocatedQuantity;
        
        foreach (var detail in voucher.Details)
        {
            requirement.SupplySources.Add(new SupplySource
            {
                SourceType = detail.SourceType,
                SourceId = detail.SourceId,
                Quantity = detail.AllocatedQuantity,
                AvailableTime = detail.AvailableTime
            });
        }
        
        // 5. 记录日志
        context.Logs.Add(new ExecutionLog
        {
            Timestamp = DateTime.Now,
            Level = "INFO",
            Message = $"执行Pegging凭证: {voucher.GetDescription()}"
        });
    }
    
    public void ExecuteSplitVoucher(SplitVoucher voucher, ScheduleContext context)
    {
        // 1. 验证凭证
        var validation = voucher.Validate();
        if (!validation.IsValid)
            throw new VoucherValidationException(validation.Errors);
        
        // 2. 获取订单
        var order = context.Orders.FirstOrDefault(o => o.Id == voucher.OrderId);
        if (order == null)
            throw new VoucherExecutionException($"订单不存在: {voucher.OrderId}", voucher);
        
        // 3. 根据指令生成Task实例
        foreach (var instruction in voucher.Instructions)
        {
            var task = new Task
            {
                TaskNo = instruction.TaskNo,
                PlanVersionId = voucher.PlanVersionId,
                OrderId = order.Id,
                MaterialId = order.MaterialId,
                MaterialCode = order.MaterialCode,
                Quantity = instruction.Quantity,
                UOM = instruction.UOM,
                OperationSeq = instruction.OperationSeq,
                OperationCode = instruction.OperationCode,
                OperationName = instruction.OperationName,
                Duration = instruction.Duration,
                SetupTime = instruction.SetupTime,
                Status = "PENDING",
                IsLocked = instruction.IsLocked,
                IsWip = instruction.IsWip,
                IsFrozen = false,
                TaskType = instruction.TaskType,
                PriorityScore = instruction.PriorityScore,
                SplitIndex = instruction.SplitIndex,
                SetupAttribute = instruction.SetupAttribute,
                CreatedAt = DateTime.Now,
                UpdatedAt = DateTime.Now
            };
            
            context.Tasks.Add(task);
        }
        
        // 4. 更新订单状态
        order.Status = "SCHEDULED";
        
        // 5. 记录日志
        context.Logs.Add(new ExecutionLog
        {
            Timestamp = DateTime.Now,
            Level = "INFO",
            Message = $"执行拆批凭证: {voucher.GetDescription()}, 生成{voucher.Instructions.Count}个Task"
        });
    }
    
    public void ExecuteOrderScoreVoucher(OrderScoreVoucher voucher, ScheduleContext context)
    {
        var validation = voucher.Validate();
        if (!validation.IsValid)
            throw new VoucherValidationException(validation.Errors);
        
        foreach (var score in voucher.Scores)
        {
            var order = context.Orders.FirstOrDefault(o => o.Id == score.OrderId);
            if (order != null)
            {
                order.PriorityScore = score.PriorityScore;
            }
        }
        
        context.Logs.Add(new ExecutionLog
        {
            Timestamp = DateTime.Now,
            Level = "INFO",
            Message = $"执行订单打分凭证: 更新{voucher.Scores.Count}个订单的优先级分数"
        });
    }
    
    public void ExecuteFrozenMarkVoucher(FrozenMarkVoucher voucher, ScheduleContext context)
    {
        var validation = voucher.Validate();
        if (!validation.IsValid)
            throw new VoucherValidationException(validation.Errors);
        
        // 冻结Task
        if (voucher.FrozenTasks != null)
        {
            foreach (var mark in voucher.FrozenTasks)
            {
                var task = context.Tasks.FirstOrDefault(t => t.Id == mark.TaskId);
                if (task != null)
                {
                    task.IsFrozen = true;
                    task.Status = mark.ShouldRelease ? "RELEASED" : "FROZEN";
                }
            }
        }
        
        // 解冻Task
        if (voucher.UnfrozenTaskIds != null)
        {
            foreach (var taskId in voucher.UnfrozenTaskIds)
            {
                var task = context.Tasks.FirstOrDefault(t => t.Id == taskId);
                if (task != null)
                {
                    task.IsFrozen = false;
                    task.Status = "PENDING";
                }
            }
        }
        
        context.Logs.Add(new ExecutionLog
        {
            Timestamp = DateTime.Now,
            Level = "INFO",
            Message = voucher.GetDescription()
        });
    }
    
    public void ExecuteBatch(List<VoucherBase> vouchers, ScheduleContext context)
    {
        // 创建快照用于回滚
        var snapshot = CreateSnapshot(context);
        
        try
        {
            foreach (var voucher in vouchers)
            {
                Execute(voucher, context);
            }
        }
        catch (Exception ex)
        {
            // 回滚到快照
            RestoreSnapshot(context, snapshot);
            throw new VoucherExecutionException($"批量执行凭证失败，已回滚: {ex.Message}", null);
        }
    }
    
    private void Execute(VoucherBase voucher, ScheduleContext context)
    {
        switch (voucher.Type)
        {
            case VoucherType.Pegging:
                ExecutePeggingVoucher((PeggingVoucher)voucher, context);
                break;
            case VoucherType.Split:
                ExecuteSplitVoucher((SplitVoucher)voucher, context);
                break;
            case VoucherType.OrderScore:
                ExecuteOrderScoreVoucher((OrderScoreVoucher)voucher, context);
                break;
            case VoucherType.FrozenMark:
                ExecuteFrozenMarkVoucher((FrozenMarkVoucher)voucher, context);
                break;
            default:
                throw new NotSupportedException($"不支持的凭证类型: {voucher.Type}");
        }
    }
}
```

## 4.4 IBulkPersistence（批量持久化接口）

### 4.4.1 接口定义

```csharp
/// <summary>
/// 批量持久化接口
/// 负责将排产结果批量写入数据库
/// </summary>
public interface IBulkPersistence
{
    /// <summary>
    /// 批量持久化排产结果
    /// 性能要求：10万行数据 < 10秒
    /// </summary>
    /// <param name="context">排产沙盘上下文</param>
    Task BulkPersistAsync(ScheduleContext context);
    
    /// <summary>
    /// 批量插入Task
    /// 使用SqlBulkCopy实现高性能插入
    /// </summary>
    Task BulkInsertTasksAsync(List<Task> tasks);
    
    /// <summary>
    /// 批量更新Task时间
    /// 仅更新PlannedStartTime和PlannedEndTime字段
    /// </summary>
    Task BulkUpdateTaskTimesAsync(List<Task> tasks);
    
    /// <summary>
    /// 批量插入Pegging连线
    /// </summary>
    Task BulkInsertPeggingLinksAsync(List<PeggingLink> links);
    
    /// <summary>
    /// 清理旧版本数据
    /// 删除指定计划版本的所有数据
    /// </summary>
    Task CleanupOldVersionAsync(int planVersionId);
}
```

### 4.4.2 实现示例

```csharp
public class BulkPersistence : IBulkPersistence
{
    private readonly IDbConnection _db;
    
    public async Task BulkPersistAsync(ScheduleContext context)
    {
        using (var transaction = _db.BeginTransaction())
        {
            try
            {
                // 1. 清理旧数据
                await CleanupOldVersionAsync(context.PlanVersionId);
                
                // 2. 批量插入Task
                await BulkInsertTasksAsync(context.Tasks);
                
                // 3. 批量插入Pegging连线
                await BulkInsertPeggingLinksAsync(context.PeggingLinks);
                
                // 4. 更新订单状态
                await UpdateOrderStatusAsync(context.Orders);
                
                // 5. 记录执行日志
                await InsertExecutionLogsAsync(context.Logs);
                
                transaction.Commit();
            }
            catch
            {
                transaction.Rollback();
                throw;
            }
        }
    }
    
    public async Task BulkInsertTasksAsync(List<Task> tasks)
    {
        if (!tasks.Any()) return;
        
        // 使用SqlBulkCopy实现高性能插入
        var dataTable = ConvertToDataTable(tasks);
        
        using (var bulkCopy = new SqlBulkCopy((SqlConnection)_db))
        {
            bulkCopy.DestinationTableName = "Task";
            bulkCopy.BatchSize = 10000;
            bulkCopy.BulkCopyTimeout = 300; // 5分钟超时
            
            // 映射列
            foreach (DataColumn column in dataTable.Columns)
            {
                bulkCopy.ColumnMappings.Add(column.ColumnName, column.ColumnName);
            }
            
            await bulkCopy.WriteToServerAsync(dataTable);
        }
    }
}
```

## 4.7 使用示例

### 4.7.1 完整排产流程中的2号位调用

```csharp
public class SchedulingOrchestrator
{
    private readonly IDataLoader _dataLoader;
    private readonly IVoucherExecutor _voucherExecutor;
    private readonly IBulkPersistence _persistence;
    private readonly IBusinessRules _businessRules; // 5号位
    private readonly ISchedulingEngine _schedulingEngine; // 1号位
    
    public async Task ExecuteFullScheduleAsync(string domainKey, int planVersionId)
    {
        // ========== 阶段1：2号位加载数据 ==========
        var context = await _dataLoader.LoadDomainDataAsync(domainKey, planVersionId);
        var anchors = await _dataLoader.LoadHistoricalAnchorsAsync(domainKey, DateTime.Now.AddDays(7));
        context.HistoricalAnchors = anchors;
        
        // ========== 阶段2：5号位打分 + 2号位执行 ==========
        var scoreVoucher = _businessRules.OrderPrioritization.CalculateOrderPriority(
            context.IndependentDemands, context);
        _voucherExecutor.ExecuteOrderScoreVoucher(scoreVoucher, context);
        
        // ========== 阶段3：5号位Pegging + 2号位执行 ==========
        foreach (var order in context.IndependentDemands.OrderByDescending(o => o.PriorityScore))
        {
            var peggingVoucher = _businessRules.Pegging.CalculatePegging(order, context);
            _voucherExecutor.ExecutePeggingVoucher(peggingVoucher, context);
        }
        
        // ========== 阶段4：5号位拆批 + 2号位执行 ==========
        foreach (var order in context.Orders)
        {
            var splitVoucher = _businessRules.TaskSplit.CalculateSplit(
                order, context.PeggingLedgers[order.Id]);
            _voucherExecutor.ExecuteSplitVoucher(splitVoucher, context);
        }
        
        // ========== 阶段5：1号位排程 ==========
        var schedulingOutput = await _schedulingEngine.ScheduleAsync(
            context.Tasks, context.ResourceCalendar);
        
        // 更新Task时间
        foreach (var task in context.Tasks)
        {
            var result = schedulingOutput.TaskResults.First(r => r.TaskId == task.Id);
            task.PlannedStartTime = result.StartTime;
            task.PlannedEndTime = result.EndTime;
            task.ResourceId = result.ResourceId;
        }
        
        // ========== 阶段6：5号位冻结区判定 + 2号位执行 ==========
        var frozenVoucher = _businessRules.FrozenZone.Evaluate(context.Tasks, DateTime.Now);
        _voucherExecutor.ExecuteFrozenMarkVoucher(frozenVoucher, context);
        
        // ========== 阶段7：2号位批量持久化 ==========
        await _persistence.BulkPersistAsync(context);
    }
}
```
