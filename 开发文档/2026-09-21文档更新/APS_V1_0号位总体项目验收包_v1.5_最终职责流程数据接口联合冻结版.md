# APS V1_0号位总体项目验收包 v1.5

## 最终职责、流程、数据、接口联合冻结版

版本：v1.5\
适用对象：0号位项目管理、最终验收

------------------------------------------------------------------------

# 一、文档定位

本版本基于APS
V1最终冻结业务、数据、接口及1～5号位实施包，用于项目最终验收。

本版本不重新设计业务，仅同步最终实施边界：

-   业务流程闭环；
-   0～5号位职责；
-   数据责任；
-   接口责任；
-   功能验收范围。

------------------------------------------------------------------------

# 二、APS V1总体验收范围

APS V1验收包括：

1.  需求与供给承接；
2.  Pegging供需匹配；
3.  有限产能排程；
4.  Candidate计划调整；
5.  计划版本管理；
6.  复杂事实接入；
7.  用户查询与业务操作；
8.  权限与治理。

------------------------------------------------------------------------

# 三、最终职责验收

  能力             责任号位
  ---------------- ----------
  有限产能Solver   1号位
  排程运行主流程   2号位
  Pegging          2号位
  Allocation       2号位
  FinalTask生成    2号位
  规则参数治理     3号位
  Auth/RBAC        3号位
  页面与用户操作   4号位
  复杂事实ODS      5号位
  PI Position      5号位

------------------------------------------------------------------------

# 四、核心业务闭环验收

## 4.1 排程主链

    需求输入
     ↓
    Supply构建
     ↓
    Pegging
     ↓
    LogicalProductionDemand
     ↓
    有限产能Solver
     ↓
    FinalTask
     ↓
    计划发布

------------------------------------------------------------------------

## 4.2 有限产能验收

必须支持：

-   设备Resource；
-   人工Resource；
-   Resource Calendar；
-   Setup换型影响；
-   Operation Planning Mode。

------------------------------------------------------------------------

## 4.3 Operation Planning Mode

支持：

  模式              含义
  ----------------- ----------------
  FINITE_RESOURCE   有限资源约束
  UNCONSTRAINED     非有限资源约束
  WAIT_ONLY         等待约束

------------------------------------------------------------------------

# 五、数据闭环验收

## Pegging

验收：

-   Demand/Supply数量闭合；
-   Allocation正确；
-   不存在第二套Pegging。

------------------------------------------------------------------------

## PI Position

验收：

-   5号位计算；
-   2号位消费；
-   不作为Supply。

------------------------------------------------------------------------

## 跨厂事实

验收：

-   SH跨厂事实正确；
-   不形成独立Supply模型。

------------------------------------------------------------------------

# 六、用户输出验收

系统应支持：

-   甘特图；
-   订单计划查询；
-   今日/未来任务；
-   延期原因；
-   Resource影响；
-   Setup影响；
-   Supply/Pegging追溯。

------------------------------------------------------------------------

解释责任：

    1号位产生
     ↓
    2号位保存
     ↓
    5号位查询
     ↓
    4号位展示

------------------------------------------------------------------------

# 七、Candidate验收

支持：

-   Candidate创建；
-   Candidate执行；
-   Candidate比较；
-   Base PlanVersion关联；
-   运行结果追溯。

职责：

-   3号位治理；
-   2号位执行；
-   4号位操作。

------------------------------------------------------------------------

# 八、接口验收原则

治理链：

    4号位
     ↓
    3号位
     ↓
    2号位

业务链：

    4号位
     ↓
    5号位
     ↓
    2号位

禁止：

页面绕过正式服务直接修改核心数据。

------------------------------------------------------------------------

# 九、最终冻结红线

不允许新增：

-   OperationSupply；
-   OperationPegging；
-   第二套Supply；
-   第二套Pegging；
-   SetupRuntime平台；
-   CandidateInput独立平台。

------------------------------------------------------------------------

# 十、最终验收结论

APS V1形成：

-   业务闭环；
-   数据闭环；
-   接口闭环；
-   职责闭环；
-   运行闭环。

后续开发、测试、代码审核均以本验收包及对应号位实施包作为依据。
