# 一、文档说明

## 1.1 文档目的

本文档是 APS（Advanced Planning & Scheduling，高级计划与排程）系统的**功能设计说明书**，面向业务部门用户，旨在：

- 说明 APS 系统**能做什么**、**解决什么问题**
- 描述各功能模块的**业务场景**和**预期效果**
- 明确系统的**能力边界**（做什么、不做什么）
- 帮助业务部门用户理解系统设计意图，为后续验收提供参考

**本文档不涉及技术实现细节**，技术方案请参阅《APS总体方案设计》等技术文档。

## 1.2 适用读者

| 读者角色 | 关注重点 |
|---------|---------|
| **机种计划员** | 日常排程操作、甘特图使用、插单评估、计划发布 |
| **生产课长** | 执行监控、KPI分析、异常预警、审批 |
| **HOLON长** | 车间执行情况、计划查看、异常反馈 |
| **仓储物流** | 库存扣减透明化、缺料预警 |
| **制造1部管理层** | 项目价值、上线计划、预期收益 |

## 1.3 术语表

| 系统术语 | 业务含义 | 举例说明 |
|---------|---------|---------|
| **排程** | 系统自动安排"谁在什么时间、用什么设备、做什么产品" | 系统排出：MC-01注塑机，3月15日08:00-10:30，做A900外壳 |
| **甘特图** | 用横条表示每个任务的时间安排，像"时间表"一样直观 | 一根蓝色横条=一个加工任务，越长=加工时间越久 |
| **冻结区（Frozen）** | 未来3天内已确认不能随意改动的计划区域 | 已备料、已排班的计划，不被系统自动打乱 |
| **确认区（Firm）** | 未来3-10天的计划，可有限度调整，需审批 | 可以微调，但要评估影响 |
| **开放区（Open）** | 10天以后的计划，可灵活调整 | 系统每天自动重新优化 |
| **插单（CTP）** | 客户临时加单，系统快速评估"能不能做、代价多大" | VIP客户加急500件A900，系统5分钟内出评估结果 |
| **Pegging（供需连线）** | 系统自动把"需要的料"和"有的料"配对起来 | A900需要500件塑料粒子，系统从仓库库存中"预留"500件给它 |
| **血缘追溯** | 追踪一个加工任务是"为了满足哪个客户订单"而安排的 | 右键点击一个任务，看到：这是为了VIP客户张三的SO-2026001号订单 |
| **产品族** | 工艺相似、共用设备的一组产品 | A系列注塑件为一个产品族 |
| **SO（销售订单）** | 客户已下达的确定性订单 | 客户A下单500件A900，交期4月1日 |
| **SS（计划库存）** | 基于预测生成的补库订单 | 预测下月需要2000件B800，提前安排生产 |
| **SS-U（紧急补库）** | 库存低于安全线，紧急补货 | B800库存告急，紧急安排一批 |
| **BOM** | 产品的"配方表" | 做1个A900成品=1个外壳+1个内芯+3个螺丝 |
| **换型** | 设备从做一种产品切换到另一种产品所需的准备时间 | 注塑机换模具需要45分钟 |
| **工艺路线** | 做一个产品需要经过的工序和设备 | A900：注塑→挤丝→外观检查→包装 |

# 二、项目背景与目标

## 2.1 当前排产痛点

### 痛点1：人工排产效率低、依赖个人经验

**现状**：机种计划员用 Excel 手动排产，排一次需要半天到一天，且高度依赖个人经验。一旦核心计划员请假或离职，排产质量大幅下降。

**影响**：排产周期长，无法快速响应变化；排产质量不稳定；经验无法传承。

### 痛点2：插单频繁，影响评估困难

**现状**：VIP客户频繁插单，机种计划员凭经验估算"能不能做"，缺乏数据支撑。经常出现"答应了客户却做不出来"或"明明能做却拒绝了"的情况。

**影响**：插单决策靠"拍脑袋"，风险不可控；无法准确评估对现有订单的影响。

### 痛点3：跨厂协同靠人拉通，信息滞后

**现状**：多工厂协同订单需要机种计划员通过电话、邮件人工拉通，信息传递滞后且容易出错。

**影响**：跨厂订单协调耗时长；信息不同步导致重复排产或漏排。

### 痛点4：库存扣减不透明

**现状**：机种计划员需手动查询ERP库存和MES在制品数据，无法知道"这批库存已经被哪个订单预留了"。经常出现多个订单"抢同一批库存"。

**影响**：齐套判断不准确，开工后才发现缺料；库存重复承诺。

### 痛点5：排产结果不可追溯（"黑盒"问题）

**现状**：Excel排产过程不留痕，HOLON长和生产课长看到结果后，不知道"为什么这样安排"。

**影响**：车间对排产结果缺乏信任；出问题无法追溯原因。

### 痛点6：缺乏预警机制

**现状**：延期风险、缺料风险等只能靠人工发现，往往发现时已经来不及补救。

**影响**：事后救火多，事前预防少。

## 2.2 APS系统定位

**三者关系**：

- **ERP** → 管理订单和库存，是"订单源头"
- **APS** → 排程优化，是"智能调度中心"
- **MES** → 车间执行，是"执行者"

**关键定位**：
- APS **不造单** — 所有订单由 ERP 生成，APS 只负责把这些订单安排到合适的时间和设备上
- APS **不替代 MES** — APS 输出计划，MES 负责执行
- APS **不替代人** — 系统是"辅助决策工具"，关键决策仍由人做出

## 2.3 核心目标

| 目标 | 具体指标 | 说明 |
|------|---------|------|
| **上线时间** | 90天内完成V1核心版 | 聚焦核心排程能力，快速上线 |
| **排程能力** | 45万单 / 450万级Task | 满足日7000订单规模 |
| **排程速度** | 单域计算 ≤ 30分钟 | 凌晨02:00开始，早上上班前完成 |
| **插单评估** | ≤ 5分钟出结果 | 客户等得起的速度 |
| **计划精度** | 近期3天：时分精度 | 可直接指导车间执行 |
| **协同视图** | 远期90天：日/周/月汇总 | 提前识别风险，驱动协同 |

# 四、功能模块详细说明

## 4.1 每日自动排程

### 业务场景

每天凌晨 02:00，系统自动拉取 ERP 最新订单数据和 MES 库存/实绩数据，执行全量排程计算。机种计划员早上上班时，即可看到最新的排程结果。

### 功能说明

**处理流程**：凌晨02:00自动启动 → 从ERP拉取所有未完结订单 → 从MES拉取最新库存和设备状态 → BOM展开（库存够就不往下展开） → 供需匹配（自动分配库存） → 合批优化（相似需求合并，减少换型） → 时间排程（按优先级安排设备和时间） → 结果保存归档 → 早上08:00机种计划员查看结果

### 输入与输出

**输入**：ERP未完结订单（SO/SS/SS-U）、ERP库存、MES在制品/设备状态、工艺路线和BOM

**输出**：各产品族/工厂的排程甘特图、任务列表、延期预警、缺料预警

### 预期效果

| 对比项 | 现状 | 上线后 |
|-------|------|--------|
| 排产耗时 | 半天到一天 | ≤30分钟（自动） |
| 排产频率 | 一周1-2次 | 每天自动滚动 |
| 排产质量 | 依赖个人经验 | 基于算法全局最优 |

---

## 4.2 排程结果查看（甘特图）

### 业务场景

机种计划员打开系统，以甘特图形式查看排程结果。可按**产品族**、**工厂**、**时间范围**筛选，直观看到每台设备的任务安排。HOLON长可查看本车间的甘特图。

### 功能说明

**状态着色**（一眼识别计划状态）：

| 颜色 | 状态 | 含义 |
|------|------|------|
| 🔵 蓝色 | 冻结（Frozen） | 已确认的近期计划，不可自动调整 |
| 🟢 绿色 | 确认（Firm） | 已确认但可有限调整 |
| 🟠 橙色 | 锁定（Locked） | 机种计划员手动锁定 |
| 🔴 红色 | 延期（Delayed） | 预计无法按时完成 |
| ⚪ 灰色 | 开放（Open） | 远期计划，可灵活调整 |

**血缘追溯**：右键点击任意任务，可看到该任务服务的客户订单、使用的库存批次、上下游工序关系。彻底消除"黑盒"——HOLON长可以清楚知道"这个任务为什么安排在这里"。

### 预期效果

| 对比项 | 现状 | 上线后 |
|-------|------|--------|
| 查看方式 | Excel密密麻麻 | 可视化甘特图 |
| 追溯能力 | 无法追溯 | 右键即可追溯到客户订单 |
| 筛选能力 | 手动筛选 | 按产品族/工厂/时间一键筛选 |

---

## 4.3 计划冻结与确认

### 业务场景

车间已根据计划备好料、排好班，这些计划不能被系统自动打乱。机种计划员通过"冻结"功能锁定近期计划。

### 功能说明

**三段式时间围栏**：

- **冻结区（Frozen）**：未来3天，不可自动调整，调整需审批（蓝色）
- **确认区（Firm）**：3~10天，可有限调整，需评估影响（绿色）
- **开放区（Open）**：10天以后，可灵活调整，自动重排（灰色）

冻结天数可按产品族配置不同值。解冻需要发起审批，系统自动展示调整影响范围，生产课长审批后方可执行。

---

## 4.4 人工干预与调整

### 业务场景

机种计划员查看排程结果后，根据实际情况手动调整：锁定任务、调整优先级、拖拽调整时间。

### 功能说明

**支持操作**：锁定/解锁任务、调整优先级、甘特图拖拽、批量操作。

**拖拽规则**：
1. 冻结区内任务拖拽 → 提示"需审批"
2. 非冻结区拖拽 → 系统展示影响清单（哪些订单会延期、延期几天）
3. 确认后 → 系统自动重新计算所有受影响的后续任务时间

**重要**：拖拽后系统**自动重算关联任务**，而非只移动一个任务，保证计划整体一致性。

---

## 4.5 紧急插单评估（CTP）

### 业务场景

客户临时加急订单，机种计划员需快速回答：能不能做？什么时候能交？会影响哪些现有订单？

### 功能说明

**操作流程**：录入插单信息（品番/数量/期望交期/客户等级）→ 点击"评估" → 系统5分钟内出结果

**代价报告内容**：
- ✅/❌ 可行性判断
- 📅 最早完成日期
- ⚠️ 受影响订单清单（哪些订单延期、延期几天）
- 💡 建议（接受/拒绝/调整参数重评）

**后续处理**：接受插单 → 系统自动重排；涉及冻结区 → 自动触发审批。

### 预期效果

| 对比项 | 现状 | 上线后 |
|-------|------|--------|
| 评估时间 | 半天到一天 | **≤5分钟** |
| 评估依据 | 凭经验估算 | 精确的产能和库存计算 |
| 影响分析 | 不知道影响谁 | 精确列出每个受影响订单 |

---

## 4.6 供需匹配与库存透明化

### 业务场景

机种计划员需知道：库存够不够？用了哪些库存？哪些需求还没被满足？

### 功能说明

**库存来源双通道**：ERP账面库存 + MES实物库存，系统自动汇总并按优先级分配。

**分配优先级**：SO（销售订单）> SS-U（紧急补库）> SS（计划库存）。同优先级内，交期早的优先。

**核心能力**：
- 系统自动将库存分配给需求，建立一对一连线关系
- 一份库存只会分配给一个需求，杜绝"重复承诺"
- 点击任意需求/库存，可查看配对明细
- 库存不足时自动触发缺料预警

### 预期效果

| 对比项 | 现状 | 上线后 |
|-------|------|--------|
| 库存分配 | 人工"先到先得" | 按优先级自动分配 |
| 重复承诺 | 频繁发生 | 系统自动去重 |
| 缺料发现 | 开工后才发现 | 排程时自动预警 |
| 追溯能力 | 不知道库存给了谁 | 点击即可查看分配明细 |

---

## 4.7 执行监控仪表盘

### 业务场景

生产课长需实时掌控排程执行情况：哪些任务按时完成？哪些延期？整体准时率如何？

### 功能说明

**仪表盘核心内容**：
- **KPI卡片**：准时交付率、产能利用率、换型次数、延期单数
- **计划vs实际对比**：每台设备的计划进度和实际进度对比
- **延期预警列表**：哪些订单预计延期、延期原因
- **历史趋势图**：近30天KPI变化趋势

**预警类型**：

| 预警 | 触发条件 | 通知对象 |
|------|---------|---------|
| 🔴 延期预警 | 实际进度落后计划超过阈值 | 机种计划员、生产课长 |
| 🟠 缺料预警 | 库存不足以支撑计划 | 机种计划员、仓储物流 |
| 🟡 产能预警 | 设备负荷率超过95% | 机种计划员、生产课长 |

### 预期效果

| 对比项 | 现状 | 上线后 |
|-------|------|--------|
| 监控方式 | 人工巡查、电话 | 仪表盘实时监控 |
| 预警时机 | 事后发现 | **事前预警** |
| KPI统计 | 月底手动汇总 | 实时自动计算 |

## 4.8 审批管理

### 业务场景

高风险操作需生产课长审批后才能执行，确保关键决策有据可查。

### 三类审批场景

| 审批类型 | 触发条件 | 审批人 |
|---------|---------|--------|
| 冻结区任务调整 | 调整未来3天内的任务 | 生产课长 |
| SO牺牲审批 | 插单导致现有SO延期 | 生产课长 |
| 已开工任务调整 | 调整车间正在执行的任务 | 生产课长 |

**流程**：机种计划员发起（附原因+系统自动生成影响分析）→ 生产课长审批（批准/驳回）→ 全程记录审计日志。

# 五、核心业务流程图

## 5.1 日常排程流程

凌晨02:00系统自动启动 → 拉取ERP/MES最新数据 → 全量排程计算（≤30分钟）→ 结果保存归档 → 早上08:00机种计划员查看结果 → 满意则确认发布 / 不满意则手动微调 → 计划发布下发MES → 车间执行、MES报工

## 5.2 插单评估流程

接到客户插单需求 → 机种计划员录入插单信息 → 点击"评估"（≤5分钟）→ 系统输出代价报告 → 可以插入/无法插入/调整参数重评 → 接受插单则系统重排 → 涉及冻结区则触发审批

## 5.3 人工调整流程

机种计划员发现需要调整 → 在甘特图上拖拽/锁定/调优先级 → 系统检查是否触碰冻结区 → 是则需审批，否则展示影响清单 → 确认后系统重算受影响任务

## 5.4 MES报工反馈流程

车间执行生产/MES报工 → APS接收报工事件 → 更新任务实际进度 → 检查是否偏离计划 → 偏离则触发预警并评估是否需要局部重排

## 6.1 APS 做什么

| 能力 | 说明 |
|------|------|
| ✅ 自动排程 | 根据订单、产能、库存自动计算最优排程方案 |
| ✅ 插单评估 | 快速评估插单可行性和代价 |
| ✅ 供需匹配 | 自动把库存分配给需求，建立可追溯的连线关系 |
| ✅ 预警监控 | 延期预警、缺料预警、产能预警 |
| ✅ 甘特图展示 | 可视化排程结果，支持拖拽调整 |
| ✅ 计划版本管理 | 保存排程历史，支持对比和回溯 |
| ✅ 审批管理 | 关键操作审批流程 |
| ✅ KPI统计 | 准时率、产能利用率、换型次数等 |

## 6.2 APS 不做什么

| 能力 | 说明 | 谁来做 |
|------|------|--------|
| ❌ 创建订单 | APS不会凭空创建新订单 | ERP负责 |
| ❌ 管理工艺 | APS不管理工艺路线定义 | MES/工艺部门负责 |
| ❌ 替代MES执行 | APS只输出计划，不直接控制设备 | MES负责 |
| ❌ 管理仓库 | APS不管理出入库操作 | WMS/MES负责 |
| ❌ 自动下发 | 计划必须人工确认后才能下发 | 机种计划员确认 |
| ❌ 采购下单 | APS只输出采购建议，不直接下单 | 采购系统负责 |
| ❌ 质量管理 | APS不处理质量异常和返工（V1.0不做） | MES/QMS负责 |

## 6.3 与ERP的数据交互边界

| 方向 | 数据内容 | 说明 |
|------|---------|------|
| ERP → APS | 订单（SO/SS/SS-U）、库存、BOM、物料主数据 | 每天凌晨全量拉取 |
| APS → ERP | 计划确认状态、计划时间回写 | 确认后回写 |

**关键规则**：ERP是订单和库存的"唯一真相源"，APS不会修改或删除ERP中的订单。

## 6.4 与MES的数据交互边界

| 方向 | 数据内容 | 说明 |
|------|---------|------|
| MES → APS | 实物库存、在制品进度、设备状态、报工实绩 | 实时反馈 |
| APS → MES | 排程计划、派工清单 | 确认后下发 |

**关键规则**：MES是车间执行的"唯一真相源"，计划下发后由MES负责执行，MES实时反馈报工数据给APS。

# 九、常见问题（FAQ）

### Q1：系统排错了怎么办？

APS不是全自动系统，关键计划必须经过机种计划员确认后才能下发。如果发现排程不合理，可以：
- 手动调整（拖拽、锁定、换序）
- 锁定满意的部分，让系统只重排其余部分
- 系统每天凌晨自动重排，第二天会根据最新数据优化

### Q2：ERP数据变了怎么办？

系统每天凌晨02:00自动全量拉取ERP最新数据，第二天的排程结果会自动反映最新变化。如果是日间紧急变化（如紧急插单），机种计划员可以手动触发局部重排。

### Q3：多个VIP客户抢产能怎么办？

系统按照**优先级打分机制**自动排序：
1. SO（销售订单）优先于SS（计划库存）
2. VIP客户优先于普通客户
3. 交期紧急的优先于交期宽松的

如果仍有冲突，系统会输出冲突列表和代价分析，供机种计划员和生产课长决策。系统不会自动"牺牲"任何已承诺的SO，必须经审批流程。

### Q4：车间不按计划执行怎么办？

MES会实时反馈报工数据（实际开工/完工时间），APS自动对比"计划vs实际"：
- 偏差在可接受范围内 → 仅更新状态，不做调整
- 偏差超过阈值 → 自动触发预警，通知机种计划员
- 严重偏离 → 建议触发局部重排，机种计划员决定是否执行

### Q5：系统宕机了排产结果丢了吗？

不会。每次排程完成后，系统会自动保存排程结果快照。即使系统临时不可用，最近一次的排程结果仍然有效，车间可按已下发的计划继续执行。系统恢复后自动加载最新快照。

### Q6：不同产品族可以用不同的排程策略吗？

可以。系统支持按**产品族维度**配置不同的排程参数：
- 不同的冻结天数（A产品族冻结3天，B产品族冻结5天）
- 不同的合批策略（有的产品族鼓励合批，有的不允许）
- 不同的优先级权重

这些策略由机种计划员（主管）在系统中配置，修改后下次排程自动生效。

### Q7：能看到未来90天的排程吗？

可以。系统提供两种视图：
- **近期执行视图**（未来3天）：精确到时分，可直接指导车间执行
- **远期协同视图**（未来90天）：按日/周/月汇总，用于提前识别缺料、产能缺口等风险

远期视图不用于直接下发车间，而是帮助管理层提前做好协同决策。

### Q8：系统上线后，机种计划员还需要做什么？

系统是"辅助工具"，不是"替代工具"。机种计划员的角色从"手动排产"转变为"审核与决策"：
- **每天**：查看排程结果，确认无问题后发布
- **需要时**：处理插单评估、手动微调、处理异常预警
- **定期**：维护排程策略配置（冻结天数、合批规则等）
- **重要决策**：审批冻结区调整、SO牺牲等高风险操作
