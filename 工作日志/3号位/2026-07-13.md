# 3号位工作记录 — 2026-07-13

## Bug修复：StrategyProfileVersion 查询缺少 RunType 筛选

**文件：** `LPS.APS.Engine/Services/Sync/ScheduleRunService.cs`  
**方法：** `CreateScheduleRunAsync`

**问题：** 查询默认已发布策略包版本时未按 RunType 筛选，夜间全排场景下可能返回其他运行类型的默认版本。

**修复前：**
```sql
SELECT TOP 1 Id FROM StrategyProfileVersion
WHERE Status = 'PUBLISHED' AND IsDefault = 1
ORDER BY PublishedAt DESC
```

**修复后：**
```sql
SELECT TOP 1 v.Id FROM StrategyProfileVersion v
JOIN StrategyProfile p ON p.Id = v.StrategyProfileId
WHERE v.Status = 'PUBLISHED' AND v.IsDefault = 1 AND p.RunType = 'FULL_SCHEDULE'
ORDER BY v.PublishedAt DESC
```

**说明：** `RunType` 字段位于父表 `StrategyProfile`，需通过 JOIN 筛选。`FULL_SCHEDULE` 对应夜间全排运行类型。
